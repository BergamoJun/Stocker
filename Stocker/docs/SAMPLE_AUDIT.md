# 표본 규모 재검토와 다음 단계 진행 조건

확장 실험 완료 결과: [SAMPLE_AUDIT_RESULTS_20261107.md](SAMPLE_AUDIT_RESULTS_20261107.md). 120개 데이터셋을 모두 평가했으며 사전 안정성 조건은 미충족이다.

기존 합성 비교는 조건별 43사례×3시드였지만 **독립적으로 생성한 시장 경로는 3개**였다. 같은 경로의 이어지는 관측, 5개 조건의 공통 난수, 같은 경로에서의 두 특징 구성은 독립 반복이 아니다. 시뮬레이션 경로 수 512도 관측한 시장 표본 수와 다르다. 따라서 기존 결과만으로 추가 표본이 결론을 바꾸지 않을 것이라고 판단하지 않는다.

기존 3시드 결과를 다시 계산하면 강한 신호의 비용 25bp 후 평균 손익 하한은 약 +0.0700%였으나, 시드 간 변동으로 구한 참고용 명목 95% t 구간은 약 −0.8310~+0.9711%다. 세 시드 평균의 정규성 가정은 매우 약하며 이 구간 자체도 실제 수익성을 검증하지 않는다. 작은 양의 점 추정만으로 표본 충분성을 판단할 수 없다는 진단이다. 확장 평가의 진행 판정은 아래의 사전 고정 24시드 정책을 따르며 이 참고 구간으로 대체하지 않는다.

## 결과 확인 전 고정한 확장

`config/sample_audit_protocol.json`의 별도 정책을 사용한다. 기존 77011/77023/77041과 겹치지 않는 새 시드 24개, 같은 5시장, 거래량 포함/제외를 평가한다. 총 120개 데이터셋·240개 학습 구성이며, 시드당 평가 사례는 43개에서 86개로 늘린다. 경로마다 1,315개 합성 일봉을 생성한다.

학습·오차 추정·평가의 경계를 원래 사례 번호 124/165에 고정하여 학습 123개와 오차 추정 40개를 유지한다. 평가 기간만 늘려 모델 학습량 증가 효과가 섞이지 않게 한다. 스트레스 시작도 원래 첫 평가 기준일 다음인 일봉 인덱스 885에 고정한다. 새 입력/경계 선택은 기존 동결 정책을 수정하지 않는 선택적 인터페이스다.

더 긴 평가 기간은 새로운 시기·신호 국면을 포함한다. 따라서 평가 사례를 복사·재표집해 숫자만 늘리는 방법과 다르다. 다만 동일 생성기의 구조적 한계는 남으며 합성 표본 증가가 실제 BE 자료의 부족을 해결하지는 않는다.

## 불확실성 계산 단위

각 시드에서 모형들의 공통 예측 가능 사례로 평균을 낸 뒤 그 시드 평균을 하나의 관측으로 사용한다. 한 경로 안에서 86개 사례가 독립이라고 가정하지 않는다. 조건 간 공통 난수는 모델 차이를 비교하는 데 사용하며 독립 시드 수에 추가하지 않는다. 추가 길이의 차이는 같은 시드끼리 짝지어 계산한다.

주요 지표는 거래량 포함 ML−고정 EWMA의 고점 MAE 차이(ATR)와 편도 25bp에서의 평균 손익 하한(%)이다. 시가 갭 미진입/현금·동일 일봉 모호성 경계는 기존 후속 정책대로 보존한다. 지원 범위 밖 예측은 현금 0으로 대체하지 않는다.

비교는 다음 두 가지다.

1. 같은 시드에서 평가 86개 평균−처음 43개 평균. 계수와 오차 추정은 같다.
2. 새로운 독립 시드 앞 12개와 뒤 12개의 86사례 평균 차이.

사전 연구 허용오차는 고점 오차 차이 0.05 ATR, 손익 하한 차이 0.10%p다. 시장에서 검증한 최적 기준이나 투자 위험 선호를 뜻하지 않는다. 작동 예: 점 추정 차이가 0이어도 불확실성 구간이 −0.3~+0.3%p라면 동일한 결과라고 판정하지 않는다.

## 구간과 진행 판정

시드별 값의 유한 분산과 평균의 근사 정규성을 가정한 t 구간을 사용한다. 24개 시드 평균/짝 차이는 자유도 23의 임계값 상향 반올림 3.486, 독립 12개 두 묶음의 차이는 Welch 자유도의 보수적 하한 11에서 4.026을 사용한다. 명목 개별 구간 수준은 99.8%다. 정규성/유한분산 가정이 약하면 구간 해석도 제한되며 분포와 무관한 보장이 아니다.

5조건×2지표×2비교=20개 판정 구간에 Bonferroni 합을 적용한 명목 가족 오류 상한은 4%다. 모든 24개 시드의 결과를 소비하며 결과가 마음에 드는 시점에 조기 종료하거나 시드를 교체하지 않는다. 근거: [NIST 평균 구간](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm), [t 임계값 표](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3672.htm).

다음 연구 단계 진행 조건은 **모든 20개 구간이 해당 허용오차 안에 들어오고, 계획한 모든 경로가 완료되며, 각 경로의 공통 예측 비율이 90% 이상**인 것이다. 차이가 통계적으로 유의하지 않다는 이유만으로 조건을 통과시키지 않는다. 누락/실패한 경로도 남기고 조건 통과를 위해 삭제하지 않는다.

이 조건을 통과해도 실제 시장 성능 승인이나 투자 보고서 점수 활성화는 아니다. 통과 시 다음 비용·위험·보류 조건의 **연구**를 진행할 수 있다는 의미다. 통과하지 못하면 추가 표본의 영향이 작다고 확정할 수 없음을 보고하고, 다음 단계를 자동으로 진행하지 않는다. 불확실성이 크다는 결과와 실제로 차이가 크다는 결과도 구분한다.

## 실행과 기록

```powershell
./.venv/Scripts/python.exe -B -m research.sample_audit
```

실제 가격 파일을 받지 않는 합성 전용 경로다. 월 데이터 예산·LLM 호출/토큰은 0이다. 사전 등록, 코드 원본/해시, 시드·조건별 진행 파일, 압축된 개별 결과, 전체 판정 JSON/Markdown을 ignored `reports/private/sample_audit/<시각>/`에 보존한다. 로컬 작업 프로세스 6개로 실행하며 각 프로세스의 BLAS 스레드는 1개로 제한한다. 실패는 표본에서 사라지지 않는다.

실제 BE 학습은 별도의 데이터 권한 확인이 필요하며 이번 검사는 해당 권한을 활성화하지 않는다. 실제 데이터의 과거 관측시각·뉴스/공시 이력·더 긴 평가 표본 확보도 후속 실증 검증에서 별도로 해결한다.
