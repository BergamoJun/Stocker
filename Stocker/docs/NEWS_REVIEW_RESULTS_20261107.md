# 2026-11-07 뉴스 연결·평가 절차 진행 결과

이번 단계에서 평가한 것은 **뉴스를 모으고 검토한 내용을 계산에 넣는 프로그램의 동작**이다. 실제 뉴스가 BE의 미래 수익률을 더 정확히 예측하게 만들었는지를 검증한 실험은 아니다.

## 실제 자료를 어디까지 확보했는가

GDELT를 허용된 네트워크에서 한 차례 다시 확인했으나 HTTP 429(요청량 제한)를 받았다. 업종 첫 요청이 실패했고 거시경제/정치·원자재 요청은 공유 대기 규칙으로 보류됐다. 실행 환경의 네트워크 차단으로 생긴 오류와 공급자가 실제로 반환한 429를 구분해 기록했다. 이후 GDELT 추가 반복은 하지 않았다.

무료 보완 경로에서 BE 회사 뉴스 원문 링크 1건과 EIA 공식 링크 3건을 확보했다. EIA 피드의 ISO-8859-1 문자 인코딩을 처리하도록 수정했다. 메타데이터 검사를 통과하지 못한 1건은 제외했고 최근 7일을 벗어난 항목도 최신 목록에 넣지 않았다. 연준 통화정책 피드에서는 해당 기간에 들어오는 항목을 찾지 못했다. 이 결과가 통화정책 위험이 없다는 뜻은 아니다.

네 링크 모두 원문 발행 시각·실제 사건·BE에 미칠 영향의 검토를 기다린다. 공식 에너지 자료를 확보했어도 일반 업종·세계 경제/정치·원자재 뉴스 검색이 끝났다고 처리하지 않았다. 현재 뉴스 전체 점수는 비워 두며, 0점이나 중립점수로 대신하지 않는다.

## 어떤 기능을 완성했는가

1. 무료 공식 RSS 연결: 제목·공급자 표기 날짜·원문 링크만 보관한다. 본문·이미지·요약·공급자 감정 판정은 저장하지 않는다.
2. 원문 검토 대기 목록: 기사마다 무엇을 확인해야 하는지 질문을 제시하고 빈 검토 양식을 만든다. 초안은 승인된 검토가 아니다.
3. 근거 검사: 관측 뒤 검토했는지, 실제 원문 발행 시각을 확인했는지, 같은 기사·메타데이터를 인용하는지 검사한다. 관련성 설명·반론·앞으로 확인할 사건도 요구한다.
4. 점수 연결: 기존 수식으로 호재를 가산하고 악재를 감점한다. 최근 사건은 양쪽 모두 더 크게 반영한다. 같은 사건의 중복·재보도는 가산하지 않는다. 자료나 검토가 빠졌으면 점수를 보류한다.
5. 장애 처리: 한 공급자의 잘못된 자료가 다른 공급자의 정상 링크까지 지우지 않도록 했다. 캐시 재사용 시 최초 관측일을 새 시각으로 바꾸지 않는다.
6. 기록 보존: 기존 가격·비용 사전 판단을 수정하지 않았다. 새 정보는 새 보고서와 검토 기록에 남긴다. 실제/가상 입력 분류와 파일·정책·계산 코드의 해시도 저장한다.

수식의 영향 크기·관련성·신뢰도·24시간 반감기·사건 중복 처리와 전체 뉴스 40점 비중은 기존 정책을 유지했다. [파라미터와 입력 방법](NEWS_EVENT_REVIEW.md)에 설명했다.

## 테스트 결과는 무엇을 뜻하는가

전체 자동 테스트 285개가 통과했다. 새 실제 보고서와 별도 뉴스 검토 CLI를 실행해 파일 형식, 코드·정책·근거 파일의 해시, 최초 사전 기록 보존, 실제/가상 분류와 점수 보류 상태도 확인했다.

가상 기사와 검토 입력으로 다음 동작을 확인했다. 같은 강도의 호재와 악재가 반대 방향으로 반영되고, 오래된 사건은 영향이 줄어들며, 재보도·중복이 점수를 늘리지 않았다. 초안·잘못된 원문 날짜·미검토 기사·새 기사 추가·미확인 주제·오래된 자료는 점수를 만들지 않았다. ISO-8859-1/UTF-8 문자 보존과 비정상 XML·외부 호스트·사용권·캐시·자료 결손도 검사했다.

통과한 테스트는 프로그램이 정한 규칙을 따른다는 근거다. 사람이 입력한 사건 해석이 옳다는 보증, BE 상승 확률, 뉴스가 수익률을 개선했다는 실증 결과는 아니다. 예제 파일과 예제 CLI 결과에는 가상 데이터 표시를 붙였다.

## 다음으로 확인할 것

원문의 관련성과 사업 영향을 검토하고, 아직 확인하지 못한 일반 뉴스 주제를 보완해야 한다. 실제 예측 검증은 2026-11-09~11-13의 5거래일 관찰이 끝나야 한다. 무료 자료로 결과를 조회할 수 있는 가장 이른 예상 시각은 11월 14일 14:02 한국 시간이다. 현재 실제 결과 확인은 0건이다. 한 기록의 결과만으로도 예측력을 승인하지 않는다.

월 데이터 예산 $0, 프로그램의 외부 LLM 호출·토큰 사용 0을 유지했다. 유료 플랜·자동 가입·실데이터 ML 학습을 활성화하지 않았다. 정식 목표가·투자 매력도·수익 실현 시기는 기존 검증 조건이 충족될 때까지 보류한다.
