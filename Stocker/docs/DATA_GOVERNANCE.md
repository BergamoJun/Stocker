# 데이터 계약·신뢰성·사용권

## 데이터 우선순위

1. 규제기관의 공시(미국 SEC EDGAR, 한국 금융감독원 OpenDART)
2. 발행사의 공식 실적발표·IR·ETF 공시/상품설명서
3. 사용 허가를 받은 가격·지수·기업행동(corporate action) 벤더
4. AI 및 공개 이용권이 확인된 공식 원천 거시통계(예: BLS·BEA; FRED API는 현재 연결 보류)
5. 검증 가능한 뉴스/애널리스트 의견(사실과 견해 구분)
6. 소셜 미디어/커뮤니티는 **심리·주장 확인용 보조**로만 활용

## 최소 데이터 레코드

| 필드 | 의미 |
|---|---|
| `source_id` | 안정적인 로컬 증거 식별자 |
| `instrument_id` | ticker만 아닌 거래소·종류 등 안정적 식별 키 |
| `source_url` | 원문 주소(실제 존재·내용 일치 검증) |
| `publisher` / `source_type` | 발행기관 및 권위 등급 |
| `published_at` | 처음 대중에 공개된 일시 |
| `retrieved_at` | 시스템이 데이터를 가져온 일시 |
| `as_of` | 리포트가 참조하는 과거 시점 컷오프 |
| `effective_period` | 재무 분기·기간 또는 시세 거래일 |
| `currency`, `unit`, `adjustment` | USD/KRW, 주·백만 단위, 수정주가 여부 |
| `raw_hash`, `revision_id` | 원문 스냅샷 및 데이터 정정 추적 |
| `license_tag`, `redistribution_allowed` | 이용권·재표시 가능 범위 |

**중요:** `published_at <= as_of`가 충족되지 않으면 해당 지식을 과거 시점 리포트에서 제거한다. 수정된 경제지표는 당시 관측 가능한 값과 최종 수정치를 구분한다. 현재 개인용 CLI는 개인 수집·저장·로컬 계산 권리를 확인해 API를 연결하며 AI 전달 권리와 분리한다. 외부 LLM 전달은 별도 확인 전 OFF다.

Massive Basic의 과거 일봉을 현재 내려받으면 available_at은 실제 조회시각이다. 공급자의 t는 바 시작시각이며 발행/가용시각이 아니다. period_ended_at은 캘린더 종료시각으로 별도 보존한다. point_in_time_verified=false 입력으로 과거 walk-forward/기간 예측을 자동 실행하지 않는다. 계정/플랜/공급 권리 종료 시 이용 중단·삭제 규칙을 다시 확인한다.

가격 스냅샷 계약 1.1.0은 volume을 exact_decimal_string_shares로 선언한 십진 문자열로 보존한다. API의 number 거래량을 정수로 절삭/반올림하지 않는다. 계산 엔진도 Decimal을 사용하고 음수·비유한 값·불명확한 float 입력을 거절한다. 기존 버전 미기재/1.0.0의 정수 거래량 입력은 호환 유지한다. 투자 보고서 계약 0.2.0과 별개인 입력 계약이다.

## 신규 커넥터 필수 체크

- 무료/유료, 개인/사업·재배포·상업적 2차 가공 허용 범위
- 종가/지연/실시간 구분 및 시세 타임존; 데이터 재사용 권리
- API key, 초당 호출·일일 quota, 캐시 가능성, 장애 시 정책
- 분할·배당·배당락/거래정지/상장폐지와 심볼 변경 보정
- 컨센서스·시세·보유종목 데이터의 제공 시점과 빈도

`config/data_sources.yaml`은 **후보 목록**이며, 연결이 완료됐다는 의미가 아니다. 웹에서 찾을 수 있는 가격이 있다고 해서 유료/공개 서비스가 그 가격을 배포할 권리가 생기는 것은 아니다.

## 신선도 정책(가안)

- 실시간 가격: 해당 계약 및 거래소 지연 요건에 따라 표기. 권리 확인 전 **미지원**.
- 종가: 최근 완료된 정규장 세션이 무엇인지 명시. 휴일/시간외 구분.
- 재무 공시: 마지막 가용 발표일·해당 회계기간을 명시. 다음 분기 실적을 추측하지 않는다.
- ETF 편입비중: 운용사 최신 발표일 표시; 오래된 구성으로 현재 노출을 단정하지 않는다.
- 뉴스: 기사 작성/수정일, 사건 실제 발생일, 검색일을 분리.
- 거시: 원 시리즈 단위·조정·주기·수정 이력을 보존. 공급자 약관상 AI 사용과 캐싱이 허용되는지 별도 확인.

## 실패 정책

- 필수 소스 실패 → `data_status.missing` + `limitations`를 생성하고 해당 항목에 대한 확정적 서술 금지.
- 서로 모순되는 소스 → 원자료·기준일·단위를 대조, 해결 전 한 값으로 병합하지 않음.
- URL 불명/인용 불일치 → 출처 주장 제거하거나 리포트 실패 처리.

## 스윙 데이터 계약

- 기준가격은 종가/지연 여부, 관측시각, 거래소·시간대, 정규장 세션 날짜, 통화, 현재 주식수 기준 가격, 과거 OHLCV의 조정 방식, 원본 snapshot/hash와 source IDs를 보존한다. 지연 분 수가 미확인이면 지연 시세를 사용하지 않는다.
- P/T/I와 거래량·수익률 계산은 기업행동과 같은 기준시점을 공유해야 한다. 총수익 수정지수를 실제 거래가격에 직접 대입하지 않는다.
- 거래소 캘린더 ID/버전, 다음 5개 세션의 관찰기한, 별도의 재평가/만료 시각을 기록한다. 주말·휴일을 단순한 5일 덧셈으로 처리하지 않는다.
- 기본 EOD 스윙은 기준 세션 다음 정규장 종료까지 유효하며 새 세션 스냅샷이 나오면 갱신한다. 휴장/시간외를 구분하고 만료된 결과는 과거 자료로 표시한다. 지연 시세 TTL은 공급자 조건과 검증된 정책이 없으면 미지원이다.
- 미래 촉매 일정은 `as_of` 이전에 공개·확인된 일정만 사용한다. 이후 공표/수정된 일정은 과거 리포트에 소급 주입하지 않는다.
- 권리 미확인·오래된 가격·상품/통화/조정 불일치 시 가격 계획과 가격 기반 점수는 보류한다. 섹터 proxy와 본문 대상은 서로 구분한다.
- 매력도/목표/기간 방법론·검증 기록·입력 스냅샷·계산 결과는 함께 보존한다. 입력 검사와 후보 계산은 연구용으로 구현했으나 실제 공급자 자동 연동과 공개 제공 파이프라인은 아직 준비되지 않았다.

세부 계산·보류 계약은 SWING_REPORT_SPEC.md를 따른다.

## 최신 뉴스·원자재 입력

GDELT의 first_seen_at은 원 발행일이 아니다. published_at, 사건 최초 공개시각, GDELT 관측시각, 조회·검토 시점을 분리하고 as_of 이후의 지식을 소급 사용하지 않는다. 기사 재노출·수정 시각을 검증 없이 신규 호재로 간주하지 않는다. 같은 사건의 여러 기사는 하나의 event_id로 병합하며 모순되는 방향은 보류한다.

메타데이터·원문 URL만 저장하고 본문/이미지·언론사 텍스트의 LLM 입력은 별도 권리 확인 전 OFF다. 원자재 값은 뉴스 제목에서 추정하지 않으며 EIA 같은 공식 API도 실제 발표/관측일·단위·제3자 권리를 확인한다. 현재 EIA는 키와 시리즈 선정 전이라 연결하지 않았다. 수집 실패·부분 커버리지·오래된 캐시는 중립 뉴스가 아니다. 각 권한과 모델 후보는 config/source_entitlements.json과 MARKET_PREPARATION.md에 기록한다.
