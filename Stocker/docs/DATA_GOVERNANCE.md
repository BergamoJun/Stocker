# 데이터 계약·신뢰성·사용권

[AI 신뢰성·기업 노출·사건 평가](../reports/private/reliability_case/20261110/DEVELOPMENT_REPORT.ko.md)를 1→2→3 순서로 개발하고 각 검사·검토 이력을 남겼다. 신규 104개, 전체 1,223개 통과·1개 환경 건너뜀. 새 AI 후보는 메모리 부족으로 미실행이며, 기업별 직접 경제 노출과 실제 사건/가격 성능은 미확정이다. 기존 실패·23변수·가격 계수·최종 잠금·예약 5개와 추천/목표가 보류를 유지한다.

[기업별 조건부 영향·반론 연결](../extensions/ISSUER_IMPACT.md)을 별도로 구현했다. BE/MSFT/XOM의 SEC 숫자·허용 공식 문단·기존 뉴스 링크를 연결하고 실제 보고서 3건을 재생했다. 실제 로컬 모델 품질 시험이 고정 기준에 미달해 기업 보고서의 AI 채택은 보류한다. 주가 효과·추천 점수는 보류한다. 새 검사 41개, 전체 1,119개 통과·1개 환경 건너뜀. [결과와 재개 조건](../reports/private/impact_case/20261109/SUMMARY.ko.md).

요청형 뉴스는 새 전용 저장소의 임시 캐시만 기간·개수·바이트 한도로 정리한다. 사용한 메타데이터와 원래 조회 범위는 불변 보고서에 복사해 캐시 정리가 과거 입력을 바꾸지 않게 한다. 보고서 상한에 도달하면 요청 전 중지하며 기존 기사/가격/공시/보고서는 삭제하지 않는다. 공급자 게시 표기·색인 관측·실제 수신·최초 보관을 구분하고 본문·요약·감정값·키·외부 AI·학습권 확대는 배제한다. [저장·시각 규칙](../extensions/ON_DEMAND_NEWS.md).

거래대금 후보는 이미 허용된 로컬 일봉의 종가×보고 거래량 근사값을 사용한다. 정확한 체결 거래대금이나 기관 순매수로 표시하지 않는다. 새 수집·외부 추론·학습 권한은 추가하지 않으며 소수 거래량·조정 단위·출처와 방법 해시를 유지한다. 기존 재생 완료 자료를 원본 해시·계산으로 연결한 뒤 개발/검증만 비교한다. 현재 뉴스·재무 소급과 최종 기업/기간 읽기는 금지한다. [저장·재생·한도](../extensions/TURNOVER_RESEARCH.md).

최신 자동 확장은 허용 공식 연준·EIA 문단만 로컬 Qwen3-4B 추론에 사용한다. 상용 가격·파생값·뉴스 메타데이터·환경변수 비밀값은 모델 입력에서 제외한다. 공개 모델/런타임을 프로젝트 내부에 고정 리비전·파일 해시로 보관하고, 판독 캐시의 최초 실제 이용 가능 시각·거부 기록·출처/문단/방법 해시를 유지한다. 외부 추론·재학습·가격 자료 학습권 확대는 활성화하지 않는다. 과거 계수 검사는 당시 가격 접두 자료만 사용하며 현재 원문·재무를 과거에 채우지 않는다. [구현·운영 범위](../extensions/AUTONOMOUS_RESEARCH.md).

[가중 엔진](../extensions/WEIGHTED_ENGINE.md)은 원래 공통 입력을 변경하지 않고 별도 ENGINE/ANALYSIS/한국어 연구 보고서를 저장한다. 가격·파생값은 로컬에만 두며 허용 공식 문단과 SEC 숫자에서 규칙 분석을 수행한다. 생성 시각과 사용 자료 기준시각, 최초 공개와 실제 보관 시각을 분리하고 출처·방법·파일 해시를 재생한다. 규칙의 조건부 사업 해석은 사람 승인이나 가격 인과효과가 아니다. 외부 모델·훈련·주문·새 수집 요청은 활성화하지 않았다.

[공통 분석 계약](../extensions/ANALYSIS_CONTRACT.md)은 SEC의 사실 숫자와 좁게 허용한 공식 문단을 AI_INPUT으로, 개인용 가격·파생값·공급자 기사 메타데이터를 LOCAL_INPUT으로 분리한다. SEC 원문 서술 전체에 대한 AI 권리를 주장하지 않는다. [현재 EOD 입력](../extensions/MARKET_INPUTS.md)과 [재무 보완](../extensions/FINANCIAL_FILL.md)은 실제 최초 저장 시각·원문/방법 해시·기업/ETF 분류·숫자 위치를 보존한다. 고정 규칙 대조는 deterministic_source_match로 기록하고 기존 검토·사람 승인과 구분한다. 외부 모델 호출·학습·공개 가격 배포는 활성화하지 않았다.

[새 공식 원문 입력](../extensions/README.md)은 사용자 지시 1→2의 별도 범위다. 연준·EIA 자체 작성 문장만 정책 문단 해시·robots·문서별 예외를 검사해 저장하고 추론 입력 적격으로 기록한다. 공개 자료 지위를 근거로 한 기술 검토이며 별도 AI 전용 허가나 제3자 본문 권리의 승인으로 표시하지 않는다. 사진·차트·표·로고·제3자 보호 자료와 전체 HTML은 제외한다. 문단 식별자·문자 위치·해시, 원문 주소·발행일 정밀도·조회/최초 보관 시각·방법 버전을 보존한다. 정확한 발표 시각이 없으면 null을 유지하며 같은 초·미래 보관 자료를 과거 입력으로 넣지 않는다. 실제/가상 공간과 기존 메타데이터 저장소는 분리한다. 외부 모델·학습은 실행하지 않으며 가격/일반 매체 원문에 대한 기존 제한도 유지한다.

[기업별 뉴스](CONTEXT_EXPANSION.md)는 프로파일·CIK·심볼·기사 버전·원문 확인·실제 검토 수신 시각을 함께 결합한다. 성공/빈 검색/부분/장애/대기와 주제별 최신성을 구분하고 캐시의 조회 시각을 유지한다. 본문·감정 판정·전체 추천 점수를 저장하지 않는다. 새 저장소와 계약을 사용해 기존 자료·검토·예측의 의미를 보존하며 실행 전후 전체 변경 범위를 확인한다.

[종합 보고서 입력](INTEGRATED_REPORT.md)은 사용권 확인 전에 가격을 읽지 않으며 실제 최초 연결 시각과 원본·권한·정규화 사본을 보존한다. 과거 조회는 같은 초·미래 입력을 배제한다. 기업 식별·EOD·조정·거래일을 대조하고 BE 전용 ETF·뉴스를 다른 기업에 붙이지 않는다. 뉴스 최신 범위 미확인은 중립이나 위험 없음이 아니며 원자재 수치를 제목에서 추정하지 않는다. 실제 가격·기사·검토 문안은 개인용 파일에만 남긴다.

[QoQ·TTM 기간 연결](SEC_QOQ_TTM.md)은 새 원문 묶음과 검토의 최초 로컬 이용 시점을 보존한다. 공시 간 현재/누적/연간을 정확한 날짜·단위·귀속 범위로 대조하며 주당 가중평균 수치를 합산하지 않는다. 수정본은 선택한 동일 구성요소의 명시적 검토와 수치 대조만 허용하고 다른 위험 서술은 따로 남긴다. 전신 CIK를 자동 합치거나 현재 공시를 과거 가격 입력으로 소급하지 않는다.

[전년 비교 검토](SEC_GROWTH.md)는 동일 공시·회계 태그·단위·범위와 현재 승인 기록을 확인한다. 회계연도 누적·분기·잔액 날짜를 맞추고, 적자/0 기준 백분율·전분기/12개월 자료 부족은 보류한다. 올해 공시의 재분류된 전년 값은 당시 원본이라는 보장이 없으므로 과거 가격 평가에 소급하지 않는다.

[공시 원문 검토 기록](SEC_FACT_REVIEW.md)은 원문 행·숫자·회계 범위·이유와 보조 도구/사람 검토자를 구분해 보관한다. 원문 해시·연속 버전·수정 공시·실제 수신 시점을 확인한다. 미해결을 0으로 채우거나 지배기업 귀속 순손익을 연결 전체로 바꾸지 않는다. 오늘의 검토를 과거 가격 평가에 소급하지 않는다.

다종목 SEC 자료는 [SEC_AUTO_REFRESH.md](SEC_AUTO_REFRESH.md)에 따라 공개 공시를 개인 로컬에 수집한다. 접수일·결산일·최초 저장일을 구분하고 수정 공시·원본 변경을 보존한다. 자동 표준 재무는 원문 검토 전 상태이며 누락·기간/단위 충돌은 보류한다. 기존 사람이 확인한 BE 선택 행을 대체하거나 현재 자료를 과거에 이용 가능했던 입력으로 바꾸지 않는다.

## 데이터 우선순위

1. 규제기관의 공시(미국 SEC EDGAR, 한국 금융감독원 OpenDART)
2. 발행사의 공식 실적발표·IR·ETF 공시/상품설명서
3. 사용 허가를 받은 가격·지수·기업행동(corporate action) 벤더
4. AI 및 공개 이용권이 확인된 공식 원천 거시통계(예: BLS·BEA; FRED API는 현재 연결 보류)
5. 검증 가능한 뉴스/애널리스트 의견(사실과 견해 구분)
6. 소셜 미디어/커뮤니티는 **심리·주장 확인용 보조**로만 활용

## 최소 데이터 레코드

| 필드 | 의미 |
|---|---|
| `source_id` | 안정적인 로컬 증거 식별자 |
| `instrument_id` | ticker만 아닌 거래소·종류 등 안정적 식별 키 |
| `source_url` | 원문 주소(실제 존재·내용 일치 검증) |
| `publisher` / `source_type` | 발행기관 및 권위 등급 |
| `published_at` | 처음 대중에 공개된 일시 |
| `retrieved_at` | 시스템이 데이터를 가져온 일시 |
| `as_of` | 리포트가 참조하는 과거 시점 컷오프 |
| `effective_period` | 재무 분기·기간 또는 시세 거래일 |
| `currency`, `unit`, `adjustment` | USD/KRW, 주·백만 단위, 수정주가 여부 |
| `raw_hash`, `revision_id` | 원문 스냅샷 및 데이터 정정 추적 |
| `license_tag`, `redistribution_allowed` | 이용권·재표시 가능 범위 |

**중요:** `published_at <= as_of`가 충족되지 않으면 해당 지식을 과거 시점 리포트에서 제거한다. 수정된 경제지표는 당시 관측 가능한 값과 최종 수정치를 구분한다. 현재 개인용 CLI는 개인 수집·저장·로컬 계산 권리를 확인해 API를 연결하며 AI 전달 권리와 분리한다. 외부 LLM 전달은 별도 확인 전 OFF다.

Massive Basic의 과거 일봉을 현재 내려받으면 available_at은 실제 조회시각이다. 공급자의 t는 바 시작시각이며 발행/가용시각이 아니다. period_ended_at은 캘린더 종료시각으로 별도 보존한다. point_in_time_verified=false 입력으로 과거 walk-forward/기간 예측을 자동 실행하지 않는다. 계정/플랜/공급 권리 종료 시 이용 중단·삭제 규칙을 다시 확인한다.

가격 스냅샷 계약 1.1.0은 volume을 exact_decimal_string_shares로 선언한 십진 문자열로 보존한다. API의 number 거래량을 정수로 절삭/반올림하지 않는다. 계산 엔진도 Decimal을 사용하고 음수·비유한 값·불명확한 float 입력을 거절한다. 기존 버전 미기재/1.0.0의 정수 거래량 입력은 호환 유지한다. 투자 보고서 계약 0.2.0과 별개인 입력 계약이다.

## 신규 커넥터 필수 체크

- 무료/유료, 개인/사업·재배포·상업적 2차 가공 허용 범위
- 종가/지연/실시간 구분 및 시세 타임존; 데이터 재사용 권리
- API key, 초당 호출·일일 quota, 캐시 가능성, 장애 시 정책
- 분할·배당·배당락/거래정지/상장폐지와 심볼 변경 보정
- 컨센서스·시세·보유종목 데이터의 제공 시점과 빈도

`config/data_sources.yaml`은 **후보 목록**이며, 연결이 완료됐다는 의미가 아니다. 웹에서 찾을 수 있는 가격이 있다고 해서 유료/공개 서비스가 그 가격을 배포할 권리가 생기는 것은 아니다.

## 신선도 정책(가안)

- 실시간 가격: 해당 계약 및 거래소 지연 요건에 따라 표기. 권리 확인 전 **미지원**.
- 종가: 최근 완료된 정규장 세션이 무엇인지 명시. 휴일/시간외 구분.
- 재무 공시: 마지막 가용 발표일·해당 회계기간을 명시. 다음 분기 실적을 추측하지 않는다.
- ETF 편입비중: 운용사 최신 발표일 표시; 오래된 구성으로 현재 노출을 단정하지 않는다.
- 뉴스: 기사 작성/수정일, 사건 실제 발생일, 검색일을 분리.
- 거시: 원 시리즈 단위·조정·주기·수정 이력을 보존. 공급자 약관상 AI 사용과 캐싱이 허용되는지 별도 확인.

## 실패 정책

- 필수 소스 실패 → `data_status.missing` + `limitations`를 생성하고 해당 항목에 대한 확정적 서술 금지.
- 서로 모순되는 소스 → 원자료·기준일·단위를 대조, 해결 전 한 값으로 병합하지 않음.
- URL 불명/인용 불일치 → 출처 주장 제거하거나 리포트 실패 처리.

## 스윙 데이터 계약

- 기준가격은 종가/지연 여부, 관측시각, 거래소·시간대, 정규장 세션 날짜, 통화, 현재 주식수 기준 가격, 과거 OHLCV의 조정 방식, 원본 snapshot/hash와 source IDs를 보존한다. 지연 분 수가 미확인이면 지연 시세를 사용하지 않는다.
- P/T/I와 거래량·수익률 계산은 기업행동과 같은 기준시점을 공유해야 한다. 총수익 수정지수를 실제 거래가격에 직접 대입하지 않는다.
- 거래소 캘린더 ID/버전, 다음 5개 세션의 관찰기한, 별도의 재평가/만료 시각을 기록한다. 주말·휴일을 단순한 5일 덧셈으로 처리하지 않는다.
- 기본 EOD 스윙은 기준 세션 다음 정규장 종료까지 유효하며 새 세션 스냅샷이 나오면 갱신한다. 휴장/시간외를 구분하고 만료된 결과는 과거 자료로 표시한다. 지연 시세 TTL은 공급자 조건과 검증된 정책이 없으면 미지원이다.
- 미래 촉매 일정은 `as_of` 이전에 공개·확인된 일정만 사용한다. 이후 공표/수정된 일정은 과거 리포트에 소급 주입하지 않는다.
- 권리 미확인·오래된 가격·상품/통화/조정 불일치 시 가격 계획과 가격 기반 점수는 보류한다. 섹터 proxy와 본문 대상은 서로 구분한다.
- 매력도/목표/기간 방법론·검증 기록·입력 스냅샷·계산 결과는 함께 보존한다. 입력 검사와 후보 계산은 연구용으로 구현했으나 실제 공급자 자동 연동과 공개 제공 파이프라인은 아직 준비되지 않았다.

세부 계산·보류 계약은 SWING_REPORT_SPEC.md를 따른다.

## 최신 뉴스·원자재 입력

GDELT의 first_seen_at은 원 발행일이 아니다. published_at, 사건 최초 공개시각, GDELT 관측시각, 조회·검토 시점을 분리하고 as_of 이후의 지식을 소급 사용하지 않는다. 기사 재노출·수정 시각을 검증 없이 신규 호재로 간주하지 않는다. 같은 사건의 여러 기사는 하나의 event_id로 병합하며 모순되는 방향은 보류한다.

메타데이터·원문 URL만 저장하고 본문/이미지·언론사 텍스트의 LLM 입력은 별도 권리 확인 전 OFF다. 원자재 값은 뉴스 제목에서 추정하지 않으며 EIA 같은 공식 API도 실제 발표/관측일·단위·제3자 권리를 확인한다. 현재 EIA는 키와 시리즈 선정 전이라 연결하지 않았다. 수집 실패·부분 커버리지·오래된 캐시는 중립 뉴스가 아니다. 각 권한과 모델 후보는 config/source_entitlements.json과 MARKET_PREPARATION.md에 기록한다.
