## 실제 BE 경로

저장된 개인용 BE 가격의 권한·원본·정규화·최신 완료 세션을 검사한 뒤 고정 EWMA 통계 경로와 새 필터를 적용했다. 기준 자료는 2026-11-06 일봉이다. **현재 수치 연구 상태는 `stand_aside`**, 사유는 다음 두 가지다.

- `INSUFFICIENT_NET_REWARD_RISK`: 비용 후 손익비가 연구 기준에 미달
- `NONPOSITIVE_ESTIMATED_PATH_EV`: 일봉 모호성을 보수적으로 처리한 경로별 추정 평균 수익이 양수가 아님

이는 개인 포지션에 대한 매매 지시가 아니라 프로그램의 미검증 수치 조건 결과다. 실제 가격을 ML 학습에 사용하지 않았고 외부 LLM에 전달하지 않았다. 현재 뉴스·시장/재무 특징 결합과 실제 예측 성능 검증은 별도 미완료 상태다. 보고서 목표·매력도·기간·검증 ID는 null이다.

준비 상태 실행 중 과거 `diagnostic-...` 폴더가 최신 숫자 시각 캡처보다 먼저 선택되는 문제를 발견해 수정했다. 오래된 가격은 현재성 검사에서 거절됐고, 수정 후 11월 6일 스냅샷으로 다시 계산했다. 권한 검사 전 가격을 읽지 않는 기본 선택 원칙은 유지했다.
