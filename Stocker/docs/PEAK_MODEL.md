# 5거래일 고점·목표·기간·수익 기회 알고리즘 v1

첫 구현은 `config/peak_model_policy.json`과 research/peak_simulation.py, peak_model.py, peak_research.py에 있다. **미검증 연구 후보**이며 투자 보고서의 가격·점수·기간 제공 값은 null이다. 기존 ATR 비교 기준과 동결한 validation_protocol.json/예측 기록은 유지한다. 새 정책·입력·코드 해시를 결과 계산 전에 별도로 등록한다.

## 무엇을 예측하는가

고점은 기준 세션 다음 **5개 정규장 세션의 최고 고가**이며 동일 고가가 있으면 첫 세션을 선택한다. 작은 국지적 반등마다 생기는 첫 고점을 뜻하지 않는다. 정확히 한 가격에 확률을 붙이지 않고 **0.5 ATR 폭 가격 구간 × 고점 형성 세션(1~5)**의 분포를 계산한다.

가격 구간의 주변분포에서 질량이 가장 큰 구간을 고르고, 그 구간에 조건부인 고점 형성 날짜를 산출한다. 가장 큰 개별 가격×날짜 칸과 가격 주변분포의 최빈 구간은 다를 수 있으므로 JSON에 둘 다 보존한다. 이 질량은 **가정한 통계 모형의 추정치**이며 검증·보정한 확률이나 승률이 아니다.

목표 가격을 정했다는 사실만으로 도달 시각이 수학적으로 정해지지는 않는다. 같은 미래 경로들에서 목표 우선 도달 시각을 별도로 측정하므로 가격·기간이 함께 나온다. **고점이 형성되는 날**과 **목표에 먼저 도달한 날**은 서로 다를 수 있다. 목표 미도달·무효화 우선·같은 일봉에서 양방향 도달·진입 불가도 보존한다.

```mermaid
flowchart LR
    A[관측 완료 OHLCV] --> B[고정 EWMA 통계와 갭/장중 변동]
    B --> C[512개 5세션 경로]
    C --> D[고점 가격 구간과 형성일 분포]
    D --> E[목표·무효화 후보]
    C --> F[목표/무효화 도달 순서와 비용]
    E --> F
    F --> G[조건부 도달기간·수익 범위·수익 기회 25점]
    G --> H[가격15·실적10·시장10·최신 사건40과 결합]
```

## 1. 실제 가격에 적용한 고정 수식 엔진

기본 엔진은 fixed_ewma_simulation이다. AI/ML 가중치 학습이나 결과에 맞춘 매개변수 최적화를 하지 않는다. 개인용 가격의 직접 통계·시나리오 계산이며 외부 LLM으로 가격을 보내지 않는다. 선택 구현인 historical_analogs는 별도 학습 권리를 확인한 경우만 사용할 수 있다. Massive 약관 1조의 개인 분석 허용과 5(g)의 AI/ML 학습 제한을 같은 권리로 간주하지 않는다. [공식 약관](https://massive.com/legal/market-data-terms-of-service).

P는 최신 확보 완료 세션 종가, A는 Wilder ATR14다. 최소 60세션을 요구하고 통계 계산에는 최대 252개의 최근 수익 관측값을 쓴다. 입력의 통화·조정·현재성·원본 해시와 관측시각을 검사한다.

일별 변수는 다음과 같다.

- 갭 수익률: `g_t = ln(O_t / C_(t-1))`
- 장중 수익률: `d_t = ln(C_t / O_t)`
- 고저 범위: `r_t = ln(H_t / L_t)`
- EWMA 감쇠: `lambda = 2^(-1/20)`, 최근 순서대로 `w_k ∝ lambda^k`, 합이 1이 되게 정규화
- 평균: `m_g = sum(w*g)`, `m_d = sum(w*d)`
- 분산: `v_g = sum(w*(g-m_g)^2)/(1-sum(w^2))`; 장중도 같은 방식
- 갭 변동성: `sigma_g = sqrt(v_g)`
- 장중 변동성: `sigma_d = sqrt(max(v_d, sum(w*r^2)/(4*ln(2))))`
- 갭/장중 상관: 가중 공분산을 각각의 표준편차로 나눈 뒤 -0.95~0.95로 제한
- 로그 추세: `mu = clip(0.25*m, -0.25*sigma, 0.25*sigma)`; 갭과 장중 각각 적용

고저 범위 항은 Parkinson의 고저가 기반 분산 식을 참고했으며, EWMA·max 조합과 드리프트 축소는 이 프로젝트의 **검증 전 설계 가정**이다. [원 논문](https://www.cmegroup.com/trading/fx/files/michael_parkinson.pdf). 수익 정규성·연속 경로 가정은 갭/급락/실적 발표를 완전히 설명하지 못한다.

각 미래 세션에서 독립 표준정규 난수 Z1, Z2를 만들고 다음 로그 변동을 쓴다.

`G = mu_g + sigma_g*Z1`

`D = mu_d + sigma_d*(rho*Z1 + sqrt(1-rho^2)*Z2)`

시가는 전 종가에 exp(G)를 곱한다. 장중에는 종가 변화 D를 고정한 8단계 Gaussian bridge를 만들어 고가·저가·종가를 얻는다. 일봉 내 움직임을 실제로 관측했다는 뜻이 아니다. 이 과정을 5세션·512경로 반복한다. 난수 seed는 고정 정책 값과 기준 세션의 해시로 정해 같은 입력의 결과를 재현한다. 같은 seed의 제로 드리프트 모형과도 비교한다.

시뮬레이션 512개를 실제 독립 거래 512건으로 세지 않는다. 통계의 유효 관측량은 `1/sum(w^2)`이고 연구 점수의 표본 할인에도 이것을 쓴다. 장중 8단계라 실제 고가를 놓칠 수 있고, 5일 동안 고정한 변동성·정규 충격이 실제 꼬리 위험과 다를 수 있다. Monte Carlo 횟수를 늘리는 것으로 실증 표본 부족이 해결되지는 않는다.

## 2. 목표·하방·수익실현 시기

경로 j의 고점을 `z_j = (max(H_j)-P)/A`로 표준화한다. 0.5 ATR 폭으로 구간화하고, 최빈 구간을 `[b, b+0.5)`라고 한다.

- 고점 가격 구간: `[P+A*b, P+A*(b+0.5))`
- 연구용 1차 목표: `T = floor_to_cent(P+A*(b+0.25*0.5))`
- 무효화: 경로별 최소 저가의 ATR 단위 값의 20분위를 q라 할 때 `I = floor_to_cent(P+A*min(q,-0.5))`
- `T>P>I>0`이 성립하지 않으면 양의 목표 후보를 보류한다. 상승 구간만 골라 강제로 호재를 만들지 않는다.
- 상승여력: `(T/P-1)*100`; 손익비: `(T-P)/(P-I)`
- 편도 비용 f 반영 기준가격→목표 순수익률: `[T*(1-f)/(P*(1+f))-1]*100`

목표는 최빈 구간 안의 **하단 25% 지점**이라는 고정 실행 후보다. 가장 높은 확률의 정확한 한 가격이나 최적 매도 주문이라고 주장하지 않는다. 고점 구간의 비용 후 잠재 수익률 범위와 고점 분포의 20/50/80분위도 별도 제공한다. 기준가격 대비 기회 범위는 실제 다음 시가 진입 수익률과 구분한다.

각 경로를 다음 시가 진입 가정으로 재생한다. 시가가 목표/무효화 밖이면 진입하지 않고 현금 수익 0을 유지한다. 갭 하락은 시가, 같은 일봉에서 양방향 도달은 순서 불명으로 처리한다. 모호 경로는 손절 우선/목표 우선의 수익 경계를 둘 다 남기고 불리한 경계를 기대수익 가산점에 사용한다. 편도 10bp·25bp를 각각 평가하며 실제 세금·체결 보장은 포함하지 않는다.

기간은 (a) 최빈 고점 가격 구간에 조건부인 고점 형성일 20~80% 범위와 (b) 목표가 무효화보다 먼저 도달한 경로에 한정한 최초 도달 세션 20~80% 범위를 구분한다. (b)의 시뮬레이션 목표 도달 경로가 5개 미만이면 기간을 보류한다. 목표 미도달을 포함한 전체 관측 5세션을 확정 수익실현일로 바꾸지 않는다.

## 3. 점수 파라미터와 가산점

실험용 전체 점수는 `수익 기회25 + 가격15 + 실적10 + 시장/섹터10 + 최신 사건40`이다. 모두 있어야 1~100 정수의 experimental_score를 계산한다. 보고서 score와 검증 ID는 계속 null이다. 부족한 요소를 50점으로 채우거나 나머지 가중치를 늘리지 않는다.

| 요소 | 계산 | 최대 |
|---|---|---:|
| 비용 후 목표 상승여력 | `clip(순상승여력% / 5, 0, 1)` | 10 |
| 불리한 순서의 기대수익 | `clip(기대 순수익 하단% / 2, 0, 1)` | 7 |
| 손익비 | `clip((RR-1)/2, 0, 1)` | 5 |
| 고점 분포 집중도 | `max(0, 1-(q80-q20)/(2*max(abs(최빈 구간 중간값),0.5)))` | 3 |
| 가격 추세·거래량 | 종가>SMA20>SMA60, 5세션 상승, 상승 종가+직전 20세션 평균 이상 거래량의 충족 비율 | 15 |
| 기업 실적 | 출처 확인된 매출 YoY·GAAP 영업이익률·FCF 양수 비율 | 10 |
| 시장·섹터 | 명시한 시장/섹터 자산의 각 SMA20 상회 비율; 같은 세션·권한·출처 필요 | 10 |
| 최신 사건 | 기존 signed recency 식: 검토된 영향·방향·관련성·근거·신규성·24시간 반감기 | 40 |

앞의 네 항목 합 25점에는 `min(1, 유효 실제 관측량/30)`을 곱한다. 5%/2% 기준과 모든 배수·가중치는 사전 고정한 실험 값이며 통계적으로 최적인 값이 아니다. 높은 고점이 있어도 손절이 먼저이거나 비용 후 기대수익이 낮으면 기대수익 가점이 줄어든다. 같은 목표여도 하방이 크면 RR 가점이 줄어든다. 최신 악재는 뉴스 40점 요소를 크게 낮춘다.

현재 CLI는 가격 요소를 계산한다. 실적·명시한 시장/섹터·검토한 뉴스 입력이 연결되기 전 전체 점수는 보류한다. 결합 함수와 누락/호재·악재 테스트는 구현했다. 미검토 제목만으로 뉴스 방향이나 전 종목 추천 점수를 생성하지 않는다.

## 4. 테스트·실제 가격 진단·사후 관찰

현재 보존한 BE 480개 일봉에 동일한 84개 기준 사례를 적용하고 앞 67개·뒤 17개를 시간순으로 분리했다. 매 사례는 당시까지의 관측 기간으로만 통계를 계산하고 이후 5세션으로 평가한다. 입력 자료가 현재 조회한 수정 이력이라는 한계는 유지하므로 retrospective_diagnostic_not_validation이다.

평가 항목은 고점 가격 구간 적중 비율, 고점 형성일 오차, 동일한 가격 구간×날짜 범주의 joint Brier, 비용별 순수익과 ATR/5일 보유 비교다. 제로 드리프트 모형과 같은 범주·같은 난수를 사용해 비교한다. 모호/진입 불가를 숨기지 않고 실행 성과는 비교 모형과 공동 해결된 동일 사례에서 비교한다. 작은 평가 표본으로 확률 보정·수익성·일반화를 입증하지 않는다. 결과에 맞춘 조정은 새 정책 버전으로만 한다.

최신 입력의 연구 예측은 진입 시각 전에 peak_ledger에 새로 남긴다. 미래 5세션이 모두 관측되고 원래 가격 이력·정책이 바뀌지 않았을 때만 사후 결과를 쓴다. 실제 조회시각을 라벨 가용시각으로 보존한다. 예측/결과를 덮어쓰지 않으며 모델 v1의 ATR 기록과 섞지 않는다. 연구 계약은 schemas/peak_research.schema.json이다.

```bash
python -m research.peak_research
python -m research.costs
python -m pytest -q
```

가격 파일을 지정하지 않으면 마지막 실제 BE snapshot/개인 권한 기록을 사용한다. 기본 경로는 무료 키/네트워크/LLM 없이 저장된 가격의 로컬 수식 계산만 한다. `--engine historical_analogs`는 model_training 권리가 없으면 가격을 학습/진단하기 전에 거절한다. 과거 유사 구간 선택/가중 분포 구현은 합성 데이터로만 별도 테스트했다. [최근접 조건부 추정 참고](https://stat.cmu.edu/~cshalizi/dst/20/lectures/24/lecture-24.html), [시계열 분리 참고](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html).
