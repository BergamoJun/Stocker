# SEC 기반 보고서 첫 실행 경로

후속 [원문 검토·다종목 재무 보고서 연결](SEC_FACT_REVIEW.md)은 별도 입력 어댑터와 계약을 사용한다. 아래 BE 고정 보고서는 기존 검토 입력을 유지한다. 아래 남은 작업은 초기 경로의 범위이며 프로젝트 전체 현황은 PROJECT_STATUS.md를 따른다.

다종목 공시 자동 수집·재무 참고자료는 새 [SEC_AUTO_REFRESH.md](SEC_AUTO_REFRESH.md) 경로로 제공한다. 아래 BE 원문 검토 어댑터와 기존 보고서는 그대로 유지한다. 자동 추출 자료를 원문 검토 완료로 바꾸거나 기존 선택 행을 덮어쓰지 않는다.

## 구현 범위

블룸에너지(BE, CIK 0001664703, NYSE)의 2026년 3분기 보고서를 만드는 로컬 파일럿이다. `research_inputs/BE/2026-09-30.json`은 실제 SEC 원문을 브라우저에서 검토해 선별한 행과 정성 분석 문안을 보존한다. 합성 예시인 `examples/illustrative_report.json`과 구분한다.

입력 원문은 FY2025 10-K, 2026-Q3 10-Q, 2026-10-22 8-K Exhibit 99.1이다. 문서별 URL·SEC 접수번호·색인 URL·공개시각·조회시각을 기록했다. 접수시각은 America/New_York에서 UTC로 코드 변환했다. 검토 컷오프는 2026-11-06T17:14:16Z, 한국시간 2026-11-07T02:14:16+09:00이다.

`InstrumentResolver`는 BE만 허용하고 CIK/거래소/상품 유형을 확인한다. `SourceAdapter`는 네트워크에 접속하지 않고 저장된 선택 행을 검증한다. `MetricEngine`은 Decimal로 단위 정규화와 재무 수치를 계산한다. `ReportValidator`는 스키마와 일부 업무 규칙을 검사한다. 정성 분석은 검토해 저장한 문안이며 CLI는 계산값만 대입한다.

## 실행과 출력

Stocker 폴더에서 실행한다.

```bash
python -m pip install -e '.[dev]'
python -m research --snapshot research_inputs/BE/2026-09-30.json --ticker BE
python -m pytest -q
```

`--as-of`로 타임존이 있는 컷오프를 지정할 수 있다. 미래에 공개된 자료가 포함되면 실행을 거절한다. 기본 컷오프는 저장된 검토 시점으로, 실행할 때마다 최신 공시를 가져온다는 의미가 아니다. 다른 기업/회계기간은 현재 지원하지 않는다.

`reports/private/<report_id>/`에 다음을 저장한다. 같은 디렉터리나 파일을 덮어쓰지 않는다.

- `report.json`: 기존 계약 0.2.0의 실제 공시 기반 부분 리포트.
- `report.md`: 한국시간·기간·금액 단위·출처·근거와 반론을 표시한 한국어 보고서.
- `provenance.json`: 입력 SHA-256, 코드/스키마 SHA-256, 선택 행의 정규화 값, 산식과 입력 ID, 계산 결과, 검증 범위와 소요 시간.

## 계산 방법

- 금액 원문은 USD thousands를 USD로 정규화하며 EPS는 USD/share를 유지한다. 출력 금액은 USD million이다.
- 매출 YoY/QoQ: 비교 가능한 기간의 매출 비율에서 1을 뺀 백분율. margin: 같은 기간 GAAP 이익 / 매출.
- 9개월 FCF: 9개월 영업현금흐름 + 원문에서 음수로 표시한 현금 PP&E 취득액. 자체 정의이며 회사 발표 FCF나 분기/TTM 수치로 표현하지 않는다.
- 4분기 필요 매출: 회사 FY2026 매출 전망 하단/상단 - 9개월 누적 매출. 전망 달성 여부나 다음 분기 실적 예측을 뜻하지 않는다.
- 계산은 34자리 Decimal 문맥에서 수행하고 소수점 6자리까지 반올림해 기록한다. 화면은 2자리 표시다.
- 잘못된 기간/단위/분모, 없는 입력은 관련 수치를 null로 보류한다. 필수 수치가 없는 정성 해석도 생략한다.

## 검증의 실제 범위

출처 ID 존재, 지원 회사의 SEC Archives URL, 공개시점 <= as_of, 원문 행 위치, 기간·단위·분모, 입력과 보고서 수치의 재계산 일치, 대상 종목 유지, bull/base/bear 구분을 검사한다. 실제 원문과 해석의 내용 일치는 이 세션에서 수동 대조했으며 코드 검증 ID만으로 사실성을 증명하지 않는다.

가격 입력·목표 산정 방법·검증 모델이 없으므로 swing.status는 unavailable, price_plan과 매력도 점수는 null이다. SEC-only 보고서는 최신 공시 전체·뉴스·컨센서스·시세·시장 반응을 망라하지 않으며, 데이터 신선도/커버리지 제한을 표시한다.

## 남은 작업

자동 SEC 수집/XBRL 추출, 원문 전체의 스냅샷/해시, 다종목·다기간 지원, LLM 분석/독립 반론 생성, 완전한 사실 검증, 모델 비용 계측, 가격 공급자와 스윙 엔진, API/UI는 미구현이다. 현재 CLI에는 SEC_USER_AGENT나 OPENAI_API_KEY가 필요 없다. 자동 SEC 접근을 추가할 때는 식별 가능한 User-Agent와 접근 정책을 별도로 적용한다.

이 실행은 사용자가 요청한 로컬 리서치다. 기존 공개 데이터 이용권·뉴스·FRED·가격 기능 제한은 유지하며, 공개 배포/재사용 승인으로 간주하지 않는다. 산출물은 Git에서 제외하는 reports/private에 저장한다.
