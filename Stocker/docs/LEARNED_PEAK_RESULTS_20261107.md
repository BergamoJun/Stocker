# 2026-11-07 수치 예측 ML 개발 결과

학습형 가격 경로 모델과 시간순 비교 도구를 구현했다. **실제 BE 학습·성능 검증은 미완료**이며 아래 숫자는 모두 `ILLUSTRATIVE — NOT LIVE MARKET DATA` 합성 실험 결과다.

학습 자료·신호/무작위/정답 섞기의 정확한 의미, 비교의 한계와 후속 방향은 [실험 브리핑](LEARNED_EXPERIMENT_BRIEFING.md)에 정리했다. 신호 실험과 무작위 실험의 잡음 크기가 다르므로 신호 유무 하나의 효과로 해석하지 않는다.

입력 8개 가격 특징을 표준화한 값과 제곱항으로 향후 5일 OHLC 경로를 Ridge 회귀한다. 별도 구간의 전체 오차 경로로 고점 가격대와 고점일 분포를 계산한다. 고정 통계 엔진, 무조건부 경로, ATR 목표, 5일 보유와 비교한다. LLM 호출·토큰·데이터 구매는 0이다.

각 실험은 합성 일봉 1,100개, 미래 5일 사례 208개다. 시간순으로 학습 123개, 오차 추정 40개, 최종 평가 43개를 사용하고 경계 라벨 2개를 제거했다. 아래 MAE는 고점 중앙값의 평균 절대오차를 기준일 ATR로 나눈 값이며 낮을수록 좋다.

긍정·부정 사례 모두 보존했다. 합성 결과만으로 실제 주가 예측력이나 수익성을 주장하지 않는다. 동일 합성 실험을 두 번 실행해 지표·학습 계수 일치를 확인했고, 마지막 결과의 코드/정책 해시도 현재 파일과 일치했다. 비교에 편도 비용 10/25bp를 적용하며 동일 일봉 목표/무효화 선후 불명 사례는 공통 체결 비교에서 함께 제외하고 원래 사례와 수를 기록했다.

마지막 합성 산출물: `reports/private/learned_research/20261107T092503020839Z/learned_research.json` 및 같은 폴더의 Markdown. 전체 계수, 오차 경로, 고점 구간×일자 Brier, 분위 오차, 비용별 체결 결과, 보류 이유와 입력/코드/정책 해시를 포함한다. 결과는 Git 추적에서 제외된다.

실제 BE 실행은 `reports/private/learned_research/20261107T092513667460Z/learned_research.json`에 `data_use_not_cleared`로 기록했다. 기본 경로와 명시적 입력 경로 모두 가격 파일을 읽거나 해시하기 전에 권한을 검사한다. 이번 실행은 실제 주가를 학습하지 않았다. Massive 시장 데이터 약관 §5(g)의 명시 허용 요건을 개인용 Basic 계정만으로 충족했다고 판단하지 않았다.
