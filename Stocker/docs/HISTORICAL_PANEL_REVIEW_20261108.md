## 현재 실행 중인 것

작업 폴더는 `reports/private/historical_panel/58488d99d05b4d1e/`다. 명부 6페이지를 모두 처리해 지원 범위의 **후보 4,380종목**을 확인했다. 같은 기업의 여러 주식 종류가 포함될 수 있으므로 4,380개 기업이라고 부르지 않는다. 02:00 KST 기준 분류 처리 7종목 중 확인 6개·미확인 1개이며, 아직 표본 선정과 산업별 가격 평가 전이다. [계속 갱신되는 상태](../reports/private/historical_panel/58488d99d05b4d1e/STATUS.ko.md).

모든 분류를 처리한 뒤 결과와 무관한 순서로 산업군별 기업 100개를 고정한다. 약 20% 기업은 마지막 시험용으로 남긴다. 100개 미만인 산업군·자료가 없는 기업은 부족으로 남기고 다른 기업으로 바꾸지 않는다.

12개 산업군이 전부 100개 조건을 만족한다는 용량 가정에서 `(6페이지 + 4,380개 분류 + 가격/마지막 가격일 식별 최대 2,400회) × 15초`의 순수 요청 간격 하한은 **28.275시간**이다. 응답 시간·재시도·작업 사이 대기·PC 중단은 추가된다. 이는 실제 완료 예상 시각이나 최소 1,200개 확보 보장이 아니다. 실제 요청 상한 16,000회, 첫 시작 후 96시간 한도, 무료 계정·외부 LLM 호출 0회를 유지한다.

## 결과가 나와도 남는 조건

현재에 받은 약 2년의 수정·분할 조정 가격과 과거 기준 SIC 조회는 당시 원본 상태가 인증된 자료가 아니다. 자료가 없는 기업의 정답도 복원하지 않는다. 이 한계를 표시한 과거 진단은 유용하지만, 여러 시장 국면이나 실제 계좌 수익성을 입증하는 최종 시험으로 바꿀 수는 없다.

수집 후 자동으로 개발·중간 구간의 고점 오차, 고점 날짜와 목표 최초 도달 시기, 목표/손실 우선 도달과 비용 후 수익 범위, 단순 보유 대비 차이, 자료 부족을 산업·월·변동성·거래대금별로 저장한다. 그다음 산업군별 표본 부족과 실패를 검토하고, 같은 날짜 주식들의 동반 움직임을 반영한 불확실성을 계산한다. 개선 후보와 기준을 별도로 등록한 후에 남겨 둔 기업·마지막 기간의 시험을 진행한다. 이 최종 시험과 실제 ML 학습은 현재 작업에 포함하지 않는다.
