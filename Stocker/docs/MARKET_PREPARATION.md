# 가격 사용권·스윙 후보 모델·최신 뉴스 준비

2026-11-07 기준. 현재 사용자 확정 범위는 **개인용 로컬 리서치, 월 데이터 예산 USD 0**이다. 공개 무료 웹은 후속 검토로 보류한다(D-018). 개인 수집·저장·로컬 파생 계산에 공개/외부 AI 권리를 선행 요구하지 않는다. 투자 보고서를 더 생성하기 전에 입력 사용권과 모델 검증을 먼저 갖춘다.

## 3. 목표·무효화 후보 v0.1

ATR 고정 배수는 기존 비교 기준으로 유지한다. 현재 사용자 요청의 고점·기간·수익 기회 1차 구현은 별도 peak_model_policy.json을 쓰며 PEAK_MODEL.md를 따른다. 현재 가격을 이용한 기본 엔진은 고정 수식 통계 시뮬레이션이다. 학습형 유사구간 엔진은 별도 학습 권리 확인 전 실데이터에서 OFF다.

최소 60개 완료 세션의 동일 기준 USD OHLCV와 등록된 권한 기록을 요구한다. 현재 데이터가 마지막 완료 세션을 포함해야 하며 휴장일/단축장/누락 세션을 XNYS 캘린더와 대조한다. 캘린더 라이브러리 버전을 기록하며 예외 휴장 변경은 운영상 재검토 대상이다.

- True range = max(high-low, abs(high-prev_close), abs(low-prev_close)).
- 첫 14개 true range 평균으로 초기 ATR을 만들고 이후 Wilder 방식 `(이전 ATR*13 + 현재 TR)/14`를 적용한다.
- 기준가격 P = 최신 완료 세션의 종가.
- 조건부 1차 목표 T = P + 2*ATR14, 무효화 I = P - ATR14.
- USD 0.01 기준 목표는 올림, 무효화는 내림한다. `T > P > I > 0`을 요구한다.
- 상승/하락폭·손익비는 기존 SWING_REPORT_SPEC의 산식을 따른다.
- 이 배수는 검증된 최적값이 아닌 **사전 정의한 비교 기준 후보**다. 목표가를 5일 내 도달한다는 보장은 없다.

가격 계획은 기준 세션 다음 5개 정규장 세션을 관찰한다. review_at은 5번째 종료, expires_at은 다음 정규장 종료다. 예상 도달기간과 별개이며 새 데이터/중요 사건 발생 시 더 이른 재평가가 필요하다.

## 4. 매력도 후보와 최신 정보 가중치

`config/swing_candidate_policy.json`이 코드와 공유하는 후보 설정이다. 후보는 투자 추천이나 승률로 제공하지 않는다.

| 요소 | 최대 비중 | 후보 정규화 |
|---|---:|---|
| 가격·거래량 | 20 | 종가>SMA20>SMA60, 5세션 상승, 상승 종가+직전 20세션 평균 이상 거래량의 충족 비율 |
| 기업 실적 | 15 | 검증된 매출 YoY·GAAP 영업이익률·자체 FCF가 양수인 항목 비율 |
| 시장·섹터 | 15 | 명시적으로 선정한 시장/섹터 기준자산이 각 SMA20 위에 있는 비율 |
| 손익비 | 10 | clip((RR-1)/2,0,1). 고정 ATR 후보에서는 거의 상수이며 독립적 성과 근거가 아님 |
| 최신 사건 | **40** | 종목에 대한 검토된 방향·영향·관련성·출처 근거·신규성과 시간 감쇠 |

기업 실적은 발표시각을 검증하고 후보 기준으로 120일보다 오래된 발표는 보류한다. 현 후보 실적 항목은 BE 2026-Q3/9개월 지표에 한정된다. 자동 다종목 분석·종목별 상품 구조 검증을 완료한 모델이 아니다. 시장/섹터 기준자산은 임의로 지정하지 않으며 각각의 사용권·출처와 같은 기준 세션을 요구한다.

전체 요소가 있어야 합산한다. 누락 요소를 50점으로 채우거나 남은 가중치로 재정규화하지 않는다. 후보 항목·배수·120일·가중치 모두 실증 검증 전이다. 검증 결과가 나쁘면 훈련 구간에서만 새 버전을 설계하고 평가 구간 결과에 맞춰 조용히 변경하지 않는다.

### 최신성은 방향의 크기를 조절

최신성만으로 호재 점수를 더하지 않는다. 최신 악재는 더 큰 음의 기여를 갖는다. 경제 뉴스의 긍정적 문체가 BE에 대한 호재라는 뜻도 아니다. 예를 들어 연료비·전력 대체비용처럼 전달 경로가 상충하면 방향을 미확인/혼합으로 남긴다.

사건별 후보 강도는 `방향 * 영향 * 관련성 * 근거 가중치 * 신규성 * 2^(-나이/24시간)`이다. 영향은 low/medium/high=0.25/0.5/1, 관련성은 직접/섹터/거시=1/0.75/0.5, 근거 가중치는 primary/독립 확인/단일 신뢰 소스/미검증=1/0.8/0.6/0으로 정의한다. 이 값은 통계적 확률이나 자동 사실 판정이 아닌 실험용 규칙이다.

최초 공개시각과 기사 발행시각 중 이른 시점을 사용해 오래된 사건 재노출이 새 사건이 되지 않게 한다. 검토된 실질 변경이 있는 경우에만 변경시각으로 재평가한다. 재탕은 기여 0, 7일 초과는 기여 0이다. 동일 event_id는 한 번만 반영하며 서로 반대인 판단이 충돌하면 보류한다. 절대 강도가 큰 상위 5개 사건의 합을 -1~1로 제한하고, 후보 뉴스 요소는 `20 + 20*합`으로 0~40점이다.

신규성/방향/발행시각을 검토하지 않은 링크는 총점에 중립값으로 넣지 않는다. 수집된 링크는 영향 검토 또는 무관련 검토 기록이 필요하다. 수집 실패·부분 커버리지·30분 넘은 수집본은 뉴스 요소 자체를 보류한다. 이 절차를 자동화한 검증된 NLP/LLM 모델은 아직 없다.

## 5. 기간과 실제 데이터 평가

기간 후보는 과거에 해당 목표에 먼저 도달한 사례의 20~80 분위 세션을 계산한다. 과거 해결 사례 30개, 목표 도달 10개 미만이면 산출하지 않는다. 전체 사례 수·도달 수·중도 미도달/모호 사례를 표시하며 **도달한 경우에 한정된 분포**임을 명시한다. 고정 5거래일을 수익실현 예정일로 바꾸지 않는다.

검증 도구는 미래를 보지 않고 시간 순서로 가격 계획을 만들며, 5세션 라벨이 겹치지 않게 진행한다. 마지막 20%는 분리한 평가 구간이다. 다음 시가가 목표/무효화 밖이면 진입 불가로 기록하고, 갭 하락은 시가, 같은 일봉에서 두 가격에 닿으면 순서 불명으로 남긴다. 기본 비용은 편도 10bp의 제안 가정이며 실측 비용이 아니다. 실제 체결 성과나 세후 수익률을 보장하지 않는다.

BE 실제 가격 사전 진단 전에 훈련/평가 비율·비용 10/25bp·모호 사례·비교 기준·연구 선별 규칙을 고정했다. 480개 일봉으로 84사례 사전 진단을 실행했다. 이는 현재 수정 이력의 계산 진단이며 **시점 보존 모델 검증은 수행하지 않았다.** 추천 활성화는 별도 검증/검토가 필요하다. 뉴스 40% 모델과 뉴스 없는 기준은 동일 평가 구간에서 비교해야 한다. 현재 조회한 뉴스나 나중에 수정한 기사로 과거 시점의 최신성 점수를 소급 생성하지 않는다. 고정 프로토콜·향후 예측 기록·다음 실행 절차는 VALIDATION_PROTOCOL.md를 따른다.

## 6. 수집·하이라이트 계약

`schemas/market_context.schema.json`은 별도 메타데이터 계약 1.0.0이다. 기존 투자 보고서 계약 0.2.0에 미검증 점수를 삽입하지 않는다. 기관·원문 링크·GDELT 관측시각·조회시각·원 발행/사건 시각의 미확인 상태·분류와 검토 상태를 보존한다.

한 번 실행할 때 회사/섹터/거시정치/원자재 최대 4개 쿼리, 쿼리당 최대 25건, 요청 간 5초, 고정 API 호스트·응답 크기·타임아웃을 제한한다. 추적 파라미터를 제거해 같은 URL을 병합하고, 기사 본문·이미지·임의 URL은 요청하지 않는다. 뉴스 갱신 정책은 15분이나 상시 스케줄러는 아직 실행하지 않는다. 수집시각이 최신이라고 모든 기사가 새 기사라는 의미는 아니다.

`news_highlights.md`는 원문 링크를 별도 강조한다. 미검토 링크는 주요 뉴스 **검토 후보**이며 호재/확정 중요도 순위라고 표시하지 않는다. 실제 테스트에서 회사 쿼리 수집에 성공했으나 전체 주제 재조회는 실패도 관측했다. 무료 API의 지연·누락·가용성을 보장하지 않으며 실패를 뉴스 부재로 바꾸지 않는다.

준비 상태와 메타데이터/링크 파일은 `reports/private/model_preparation/<실행시각>/`에 저장한다. 정책·권한 기록·코드 해시를 기록한다. 허가된 정규화 가격 스냅샷이 있으면 `--prices`, `--price-entitlement`, `--ticker`, 선택한 `--scope`로 실험할 수 있다. 기본 범위는 **local_research**다. 개인용 권리를 public_report에 재사용하면 거절한다. 합성 입력과 합성 권한 기록을 실제 데이터에 재사용할 수 없다.

권리가 있는 시장/섹터 기준자산과 뉴스 영향 검토 파일까지 갖추면 `--market-benchmark`, `--sector-benchmark`, `--event-assessments`, `--news-snapshot`으로 후보 요소를 연결할 수 있다. 파일 내용의 법적 진위·검토자의 실제 사실 확인을 코드 메타데이터만으로 증명하지는 못한다.

다음 선행 조건은 본인 무료 가격 계정/키 연결, 실제 가격/뉴스 이력과 명시한 기준자산, 원자재용 EIA 무료 키/시리즈 검토, 검토된 사건 영향, 사전 평가 기준과 검증 기록이다. 공개 가격 권리는 개인용 진행의 차단 조건에서 제외했다. 모델 검증 전에는 새 투자 추천 보고서를 만들지 않는다. 기존 SEC CLI는 참고·회귀 확인용으로 유지한다.

## 8. 개인용 무료 가격 연결

1. [Massive](https://massive.com/)에서 본인 명의 Stocks Basic **$0** 계정을 준비한다. 가입 과정에서 본인의 비전문가 자격과 해당 구독자 약관을 직접 확인한다. 유료 플랜/체험/결제 수단 등록은 이 프로젝트의 요구사항이 아니다.
2. API 키를 본인 PowerShell 프로세스 환경변수에 넣는다. 아래 방식은 입력과 명령 기록에 키 값을 노출하지 않는다. 같은 터미널에서 CLI를 실행한다. IDE 프로세스는 이미 실행 중인 터미널의 새 환경변수를 자동으로 받지 않는다. `.env` 파일은 이 CLI가 자동 로드하지 않는다.

```powershell
$stockerSecret = Read-Host 'Massive API key' -AsSecureString
$stockerPointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($stockerSecret)
try {
    $env:MASSIVE_API_KEY = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($stockerPointer)
} finally {
    [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($stockerPointer)
    Remove-Variable stockerSecret, stockerPointer
}
python -m research.fetch_prices --check
python -m research.fetch_prices --confirm-personal-nonprofessional
```

확인 플래그는 본인의 무료 개인 계정·비전문가 자격·필수 구독자 동의를 완료했다는 사용자 진술이다. 키가 있다는 이유만으로 자격을 추정하지 않는다. CLI는 계정 가입/동의/요금제 변경을 수행하지 않는다. 키 값은 채팅에 보내지 않는다.

Windows 사용자 환경변수 설정에서 저장한 키는 이미 실행 중인 터미널에 자동 반영되지 않을 수 있다. 새 터미널을 열거나 같은 PowerShell에서 `$env:MASSIVE_API_KEY = [Environment]::GetEnvironmentVariable('MASSIVE_API_KEY', 'User')`로 해당 변수 하나만 불러온다. 샌드박스의 환경/사용자 레지스트리가 실제 사용자와 다를 수도 있으므로 프로세스의 키 미인식을 Windows에 저장된 키 부재로 단정하지 않는다. 준비 상태의 api_key_present는 해당 실행 프로세스에 한정된 확인이다.

요청은 BE의 일봉 한 번, 700일 범위 이내로 제한한다. 인증은 Authorization 헤더만 사용하고 키를 URL/로그에 넣지 않는다. 리다이렉트·추가 페이지·자동 재시도·유료 대체·x402 결제는 없다. 반복 실행은 계정 전체 **분당 5회** 한도 안에서 한다. HTTP 403/429/장애를 빈 이력으로 대체하지 않는다.

Basic은 ET 기준 당일 데이터를 요청할 수 없으며 전 거래일 데이터는 ET 자정 이후 제공된다. 장 종료 직후에는 최신 완료 세션과 무료 가용 세션이 달라질 수 있다. 요청은 전 ET 날짜까지로 제한하고, 최신 완료 세션이 없으면 현재 가격 계획은 보류한다. 종가를 실시간 현재가로 표시하지 않는다. 참고: [공급자 FAQ](https://massive.com/knowledge-base/categories/faq).

성공 시 `reports/private/market_data/<실행시각>/`에 raw_response.json, prices.json, price_entitlement.json, fetch_readiness.json을 저장한다. 이 폴더와 local_data/ 밖으로 저장하는 옵션은 거절한다. 키 미설정·자격 미확인은 준비 상태만 저장하고 네트워크 요청을 하지 않는다.

가격 입력 계약 1.1.0에서는 API의 소수 거래량을 십진 문자열 그대로 보존하고 로컬에서 Decimal로 계산한다. 정수 변환으로 소수부를 버리지 않는다. 음수·비유한 값·잘못된 타입은 계속 거절한다. 이전 정수형 가격 입력 계약과 명시적으로 구분하며 보고서 계약 0.2.0은 바꾸지 않는다.

준비 상태는 저장된 권한 기록 검사, 현재 프로세스의 키 인식, 가격 신선도, 모델 검증을 구분한다. 계정 권한 기록이 통과해도 가격이 오래됐으면 현재 계획은 보류한다. 다른 프로세스에서 저장한 권한 기록을 읽을 때 현재 프로세스에 키가 없다는 이유로 계정 확인을 미완료로 되돌리지 않는다.

```bash
python -m research.prepare_models --prices reports/private/market_data/<실행시각>/prices.json --price-entitlement reports/private/market_data/<실행시각>/price_entitlement.json
```

위 명령은 최신 입력이 유효하면 **현재 연구용 ATR 목표 후보**를 계산한다. 과거 이력의 available_at은 실제 조회시각이고 공급자의 t는 바 시작시각으로 분리한다. split-adjusted는 배당 조정과 다르다. 당시 가용 이력이 확인되지 않은 입력은 point_in_time_verified=false이며 자동 walk-forward·기간 예측은 보류한다. 검토되지 않은 현재 이력을 과거 가용 이력으로 바꿔서 테스트를 통과시키지 않는다. 실증 평가를 위한 시점 보존 수집/수정 이력·기업행동 검토가 별도로 필요하다.
