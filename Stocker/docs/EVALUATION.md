새 골든 사례는 가격 미확인/노후화, 휴장·만료, 역전 목표/잘못된 손익비, proxy 없는 섹터, 미검증 점수/기간, 같은 일봉에서 목표·무효화 동시 도달을 포함한다. 기존 JSONL well-formedness 테스트는 사례 실행을 뜻하지 않는다.

모델 활성화 전 시점 보존 out-of-sample/walk-forward 평가, 데이터 누수 점검, 비용·슬리피지 반영, 가격 구간/기간별 결과 및 실패·보류 비율을 기록한다. 매력도 높은 구간의 결과를 확인하되 점수를 적중 확률로 재해석하지 않는다. 목표·무효화가 같은 일봉에 걸리면 선후를 임의 추정하지 않는다. 검증 임계값·평가 기간·모집단·가중치는 사전 확정하고 결과를 본 뒤 임의 변경하지 않는다.

표본 충분성은 [SAMPLE_AUDIT.md](SAMPLE_AUDIT.md)의 별도 정책으로 평가한다. 24개 독립 시드와 43→86 평가 사례를 사용하고 학습 123개·오차 추정 40개를 고정한다. `tests/test_sample_audit.py`는 경계/계수 불변성, 시드 단위 구간, 점 추정 차이 0과 실용적 동등성의 구분, 전체 구간·커버리지·누락 경로의 다음 단계 차단을 검사한다. 최소 사례 수나 비유의성만으로 충분성을 승인하지 않는다.

후속 합성 비교는 `config/robustness_protocol.json`과 [ROBUSTNESS_PROTOCOL.md](ROBUSTNESS_PROTOCOL.md)를 따른다. `tests/test_robustness.py`는 신호 크기가 달라도 같은 난수 잡음 사용, 첫 평가 기준일 이후의 급변, 제외한 거래량의 계수/표준화/지원 검사 불참, 미지원 변형의 공통 비교 제외, 모호 체결의 비용 후 경계, 누락 기간 추정·실패 시드·전체 계획 보존, 미검증 결과 제공 차단을 검사한다. 합성 민감도 검사를 실제 BE 예측력으로 해석하지 않는다.

새 고점 후보는 PEAK_MODEL.md와 peak_model_policy.json의 별도 정책을 사용한다. tests/test_peak_model.py는 고점일/목표도달일 구분, 미래 가격·라벨 배제, 양의 기회 없는 경우 보류, 손절 우선/같은 일봉 모호성의 가산점·기대수익 감소, 비용 효과, 뉴스 40점과 결손 시 총점 보류, 학습 권리 게이트와 예측/사후 기록을 검사한다. 실제 BE 고정 통계 수식 진단은 84사례·분리 평가 17사례이며 확률 보정/실증 검증 완료를 뜻하지 않는다.

tests/test_service_budget.py는 25% 여유 토큰·무료량/비용의 분리, 공유 호출 간격, Retry-After/429 대기와 추가 호출 금지를 검사한다. 요금표는 2026-11-07 공식 자료 스냅샷이며 실제 사용량·계정 크레딧·모델 접근 한도를 확인한 결과가 아니다.

가격 사전 진단과 향후 기록은 VALIDATION_PROTOCOL.md 및 config/validation_protocol.json을 따른다. 실제 결과 계산 전 정책/규칙을 고정하고 입력·코드 해시를 기록했다. BE 480개 일봉의 84사례 사전 진단은 현재 조회본의 retrospective_diagnostic_not_validation이며 시점 보존 검증이 아니다. 뉴스/매력도 모델은 평가하지 않았다.

tests/test_validation_workflow.py는 과거 입력의 실제 관측시각 유지, 엄격한 현재성 검사 유지, 훈련/평가 라벨 구분, 미해결 사례 노출, 프로토콜 변경 거절, 등록/결과 불변성, 다음 시가 이전 기록, 5세션 관찰, 수정 이력 시 결과 보류와 실제 라벨 조회시각, 중복 실행 방지·제한된 다음 실행을 검사한다. 연구 결과는 validation_artifact.schema.json 1.0.0으로 검사하며 추천 점수/검증 ID를 차단한다. 이 계약 역시 표본 적정성·전략 성능·독립적인 등록시각 인증을 증명하지 않는다.
