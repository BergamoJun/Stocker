# PRD — Evidence-driven Equity Research (v0.3)

> 현재 사용자 확정 (2026-11-07 변경): **개인용 로컬 리서치, 월 데이터 예산 $0, 미국 주식·ETF, EOD·지연 우선**. 개인 가격 수집·저장·코드 계산은 개인용 권리로 진행한다. 공개 배포·외부 가격 LLM 입력은 OFF. 아래 웹/API 요구사항은 후속 설계로 보류하며 현재 실행 기준은 MARKET_PREPARATION.md다.

## 1. 사용자와 문제

- 1차 사용자: 본인 로컬 환경에서 자신의 미국 주식/ETF 투자 아이디어를 검증하려는 개인 사용자.
- 해결할 문제: 뉴스 요약, 재무 지표, 산업 흐름, 리스크가 서로 다른 화면에 분리되어 있고 분석의 출처 및 반대 논리를 확인하기 어렵다.
- 핵심 약속: **검증 가능한 데이터와 명시적 가정으로부터 투자 논리·리스크를 조직화**하고, 약 1주일의 스윙 판단에 필요한 가격 조건·시간 조건을 먼저 보여준다.

## 2. MVP 범위

입력:

- 검색어: ticker/기업명/섹터명 (필수)
- 시장: US 전용 (MVP), KR은 향후 확장
- 분석 유형: `equity | sector | fund` (자동 분류 후 확인)
- 기간: `swing | short | medium | long` (기본 `swing`: 약 5거래일; 기존 short 1~3개월, medium 3~12개월, long 1년 이상 유지; 분석 기간과 데이터 기간을 혼동하지 말 것)
- 옵션: 특별히 검증하고 싶은 가설, 투자 철학(가치·성장·퀄리티), 출력 깊이

출력:

- 식별된 투자 대상/상품 구조, 기준일·현재 데이터 상태
- 스윙 상단 요약: 한줄평, 기준가격·조건부 1차 목표가·상승여력, 수익실현 검토 조건/시기, 무효화 기준·하락폭·손익비, 매력도 1~100점 또는 보류 사유
- 한 문단 요약, 근거 수준, 주요 투자 가설 및 반론
- 적절한 재무/시장/섹터 지표와 출처
- 강세·기준·약세 3개 시나리오, 핵심 전제·관찰 신호·무효화 조건
- 촉매, 리스크, 데이터 결손, 출처와 조회일
- 직전 리포트와 변경점(후속 기능)

## 4. 비목표 / 경계

- 매매 주문, 자동매매, 수익 보장, 무근거 실시간 시세, 미확인 목표주가 제시.
- 초기 단계의 초단타/호가 기반 트레이딩 및 원인 없는 차트 패턴 단정.
- 컨센서스 유료 API/실시간 가격 feed가 없는데 이를 제공하는 듯한 표현.
- 공개 사용권을 확인하지 못한 EOD 가격의 표시·가공 또는 이를 사용한 PER/기술적 지표.

## 5. 품질 속성

- **정확성**: 사실 오류 0을 목표로 하되, 검증 불가/데이터 공백을 명시.
- **재현성**: 동일 데이터 스냅샷·설정·모델 버전으로 리포트 생성 과정을 재구성 가능.
- **관측 가능성**: 요청별 수집 성공/실패, 토큰/비용, 실행시간, 품질 게이트 통과율 기록.
- **보안**: 프롬프트 주입 격리, 키 비노출, 최소 수집, 사용자 데이터 별도 보호.
- **컴플라이언스**: 외부 공개/유료 서비스 전 법률 검토 필수.

## 6. 사용자 경험 예시

> 입력: `NVDA`, 미국, 중장기, "AI 데이터센터 CAPEX 둔화 가능성을 중심으로 반론까지 검토"

> 결과: 최신 확보 자료의 날짜·출처 + 실적/수요·마진·경쟁 분석 + 상반된 시나리오 + 감시 지표 + 불확실성.

결과는 생성 전에 데이터 신선도와 관련 위험을 확인한다. 리포트를 읽는 사용자가 **어떤 사실이 확인됐고 어떤 부분이 해석인지** 즉시 구분할 수 있어야 한다.

## 7. 스윙 프로필

스윙 요약은 기존 기업·섹터 분석을 근거로 사용한다. 기본은 기준가격 대비 상방 시나리오이며 공매도·개인별 진입가·주문 수량은 범위 밖이다. 섹터는 명시적으로 검증한 ETF proxy가 있을 때 그 상품의 가격 계획을 연결한다. 가격/점수/도달기간의 제공 조건은 서로 구분하며, 상세 계약·계산식·검증 기준은 SWING_REPORT_SPEC.md를 따른다.

## 8. 최신 정보와 모델 준비 우선

가격 사용권·목표/매력도/기간 검증을 추가 CLI 투자 보고서보다 먼저 진행한다. 월 데이터 예산은 USD 0이다. 경제·정치 세계 뉴스의 기업/섹터/거시/원자재 전달 경로를 최신 사건 요소로 반영하고, 주요 사건의 원문 링크를 별도 강조한다. 최신 악재 역시 영향이 커져야 하며 단순한 최신 기사 수를 호재 점수로 바꾸지 않는다.

GDELT 메타데이터는 발견/검토 후보로 사용한다. 발행·사건 시각, 신뢰 근거·독립 확인, 종목에 대한 방향/관련성을 검토해야 점수 연구에 반영한다. 원자재 숫자는 적합한 공식 수치 API와 단위/기간 검증을 별도로 요구한다. 모델 후보와 수집 실패/부분 커버리지는 사용자에게 구분해 표시한다. 상세 수용 조건은 MARKET_PREPARATION.md와 market_context.schema.json에 있다.
