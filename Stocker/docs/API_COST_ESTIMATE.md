# 요청량·무료 제공량·토큰 비용 (2026-11-07 확인)

현재 월 데이터 예산 $0을 유지한다. 유료 플랜/체험/LLM 호출은 활성화하지 않았다. 목표·고점·기간·점수 수치 계산은 Python 로컬 수식이며 **LLM 토큰과 LLM 비용은 0**이다. 데이터 API 요청 횟수와 LLM 토큰은 다른 한도다. 관측한 GDELT HTTP 429를 OpenAI 토큰 부족으로 해석하지 않는다.

공식 근거: [Massive](https://massive.com/stocks), [GDELT](https://www.gdeltproject.org/about.html#termsofuse), [GNews](https://gnews.io/pricing), [NewsAPI](https://newsapi.org/pricing).

뉴스 요청 수를 `(종목수 N + 공유 섹터수 S + 거시/정치1 + 원자재1) × 하루 조회수`로 가정한다. 조회자마다 중복 호출하지 않고 공통 캐시를 공유한다. 실제 OR 쿼리/최대 기사 수/검색 누락에 따라 달라질 수 있다.

- 1종목·1섹터, 하루 3회: **12요청/일**, 30일에 360요청.
- 10종목·3섹터, 하루 3회: **45요청/일**, 30일에 1350요청.
- 1종목, 매시간: **96요청/일**. 100회 무료 한도에 근접하며 25% 재시도 여유를 두면 120회라 부족하다.
- 1종목, 24시간 내내 15분마다: **384요청/일**. 100회 무료량은 부족하고 1000회 플랜의 요청량에는 들어간다. 12시간 지연 무료 뉴스는 별도 최신성 제약이 남는다.

EOD 가격 요청은 종목·섹터 proxy·시장 proxy를 각각 한 번 받는다고 가정한다. 1종목/1섹터는 하루 3회, 10종목/3섹터는 하루 14회다. 분당 5회 한도에서 15초 간격으로 처리할 수 있다. 이는 지원 종목/proxy가 자동 승인됐다는 뜻이 아니라 용량 산정이다.

따라서 현재 개인용 스윙·저빈도 생성에서 **가격 유료 플랜은 필수가 아니다.** 뉴스의 안정적 실시간 공급을 반드시 보장하려면 공급자 변경/유료 계약을 검토할 수 있지만, GDELT 429만 보고 유료가 필수라고 단정하지 않는다. 무료 제공량과 신선도·권리·가용성은 함께 확인해야 한다.

Massive 개인 분석과 AI/ML 학습은 별도다. 새 기본 엔진은 고정 수식 통계 분석으로 구현했고, 학습형 유사구간 엔진의 실데이터 사용은 명시적인 model_training 권한 확인 전 OFF다. 개인 유료 플랜으로 바꾸는 것만으로 학습/공개 권리가 해결된다고 가정하지 않는다. [데이터 약관 1조·5(g)](https://massive.com/legal/market-data-terms-of-service).

## 요청 제한 처리

기존 쿼리당 대기와 별도로 프로젝트 전체가 공유하는 request.lock과 request_state.json을 local_data/gdelt_budget에 둔다. 요청 완료 후 최소 15초 간격을 보장한다. HTTP 429 또는 제공자의 제한 안내 본문이면 기본 15분 동안 추가 네트워크 요청을 하지 않는다. Retry-After가 더 긴 시간/HTTP 날짜를 지정하면 그 시각을 따른다. 같은 요청을 자동 재시도하거나 키/IP를 바꾸지 않는다.

대기 중 요청도 실패/부분 커버리지로 남기며 점수 중립값으로 바꾸지 않는다. 같은 IP의 외부 프로그램이나 제공자 전체 혼잡까지 이 로컬 제한기가 해결하지는 못한다. 이 기능은 무료 플랜을 우회하는 장치가 아니라 호출 폭주 방지다.

## 향후 LLM 문안 생성 비용

`config/service_budget_policy.json`과 research/costs.py가 다음 가정으로 산출한다. 실제 LLM 호출/토큰 측정값이 아니다.

- 근거 검토: 입력 12,000 / 출력 3,000
- 반론: 입력 6,000 / 출력 1,200
- 문안 작성: 입력 8,000 / 출력 1,800
- 합계에 25% 여유: **보고서당 입력 32,500 / 출력 7,500**
- 월 22거래일. 15분 시나리오는 거래일마다 24시간 96보고서라는 고사용량 상한 예시다.
- 출력은 추론/출력 예산을 포함한 가정이며 실제 숨은 추론량은 모델 설정에 따라 달라진다. 캐시·Batch 할인·웹 검색/파일 저장 등 도구 요금·세금·환율은 제외한다.

## 무료 토큰/구독 크레딧과 비교

OpenAI API의 일반적인 무료 토큰 수가 모든 계정에 고정 지급된다고 가정하지 않는다. Free usage tier의 $100/month **사용 한도는 무료 지급액이 아니다**. [API rate limits](https://developers.openai.com/api/docs/guides/rate-limits).

현재 공식 문서에는 자격 있는 ChatGPT Pro/Business의 API 크레딧 혜택이 있다. Pro의 $100/$200/$500 티어는 각각 월 $100/$200/$500, Business Standard는 유료 좌석당 월 $20, Premium은 $100이며 Business workspace 한도·결제 주기 만료가 적용된다. 7일 이상 유지한 유료 구독·소유자/동일 이메일 등 조건과 **직접 활성화**가 필요하다. 실제 계정의 활성화·잔액·잔여 기간은 확인하지 않았다. [혜택과 조건](https://developers.openai.com/api/docs/guides/chatgpt-api-credits).

활성화된 잔여 크레딧이 $20이라면 위 가정의 10종목 하루 1회 Luna($1.54)·Terra($15.40)는 금액상 들어간다. 15분마다 Terra($147.84)는 $100 크레딧으로도 부족하다. 돈 한도에 들어가도 해당 모델 접근·RPM/TPM·다른 앱 사용·추론량 때문에 충분하지 않을 수 있다. 계획상 검증된 무료 잔액은 0으로 두며, 실제 혜택을 확인하기 전 자동 유료 사용을 켜지 않는다.
