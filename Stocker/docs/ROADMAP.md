## Phase 1: 최소 vertical slice (backend + CLI)

- 정확한 CIK-종목 식별, 타입 분류, SEC 10-K/10-Q/XBRL 어댑터
- 재무 기간·단위 정규화 및 결정론적 핵심 지표 계산
- 증거 ID → 분석 → 반론 → Schema/수치/인용 검증
- 가격 제공자 미연결 상태에서도 공시/사업 분석 생성
- 10개 골든 평가와 실패/불확실성 사례 통과
- 모델 호출 비용 및 지연 시간 계측

## Phase 2: 공개 웹 베타

- FastAPI REST, PostgreSQL, Redis 작업 큐와 조회 API
- 캐시된 리포트 우선, 동시 작업 병합, 생성 할당량, 예산 상한
- React 검색/로딩/리포트/출처 UI
- 재시도·타임아웃·에러·중지 기능·감사 로그
- 출처별 이용권 검증과 안전 공지
- 출시 전 약관·개인정보·규제 검토와 장애 대응

## Phase 3: 커버리지 확장

- 검증된 운용사 문서가 있는 ETF allowlist, 이후 레버리지 ETF 지원
- 범위가 명확한 섹터 베타
- 공개 전시/가공/LLM 이용권을 확보한 EOD 공급자 도입 후 가격·밸류에이션·차트
- BLS·BEA 같은 적합한 원천 거시 API 추가
- 이후 한국 주식, 변경 이력 비교 및 알림
