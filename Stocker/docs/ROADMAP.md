### 고점·수익 기회 1차 알고리즘

수치 예측 ML의 다음 순서는 [실험 브리핑](LEARNED_EXPERIMENT_BRIEFING.md)을 따른다. 현재 합성 결과로 기존 엔진을 교체하지 않는다. 다음 비교 정책은 같은 잡음 조건의 신호 변화·거래량 제외·여러 시드·규칙 변화를 사전 정의한다. 무료 실데이터 학습권과 충분한 평가 표본 확보를 병행하고, 실제 비교 후 뉴스 특징의 추가 기여와 비용 후 목표 우선 도달 성능을 검증한다. 480개 일봉에 현 학습 정책을 적용한 규모 추정은 최종 평가 18사례로, 실증 승인에 충분하다고 간주하지 않는다.

후속 합성 검증 CLI `research.robustness`를 구현했다. 별도 고정 정책으로 5시장×3시드×2특징 구성, 공통 예측 가능 사례, 현금/갭/같은 일봉 모호성을 포함한 비용 후 손익 경계와 목표 도달기간 평가를 수행한다. 실제 학습권 조사에서는 SimFin 개인 연구 라이선스와 공식 ML 예제를 추가 확인했으나 BE 가격 원천 조건은 미확정이다. EODHD 무료 1년 이력은 현재 검증 표본에 부족해 선정하지 않았다. 상세: [ROBUSTNESS_PROTOCOL.md](ROBUSTNESS_PROTOCOL.md), [TRAINING_DATA_REVIEW_20261107.md](TRAINING_DATA_REVIEW_20261107.md).
