# 다종목 과거 평가의 실행과 결과 확인

2026-11-08 전체 프로젝트 재검토 결과, **기존 수식을 고정한 다종목 과거 평가부터 진행**한다. BE 한 건의 향후 관찰을 기다릴 필요는 없다. SEC 기업 분석·뉴스 보관·기존 BE 예약 관찰은 그대로 유지하며, 현재 뉴스나 재무정보를 과거에 소급해서 넣지 않는다. 이 단계는 개인용·월 데이터 예산 $0의 로컬 연구다.

## 구현한 순서와 평가 질문

| 순서 | 모듈 | 하는 일 | 완료와 구별할 조건 |
|---|---|---|---|
| 1 | `sector_universe` | 2024-12-09 미국 일반주 명부·CIK 기업 식별·SIC 산업 코드 확인 | 현재 받은 과거 조회 응답이며 당시 원본 상태의 인증은 아니다. |
| 2 | `sector_universe.freeze` | 공개 FF12 범위로 12개 산업군을 나누고 결과와 무관한 해시 순서로 기업 선정 | GICS 또는 공식 Fama–French 포트폴리오의 복제가 아니다. |
| 3 | `panel_transport`·`panel_prices` | 캐시·공유 간격으로 일별 가격 저장, 마지막 가격일의 기업·주식 식별 대조 | 누락·다른 기업·지원하지 않는 거래일은 미해결이며 기업을 교체하지 않는다. |
| 4 | `historical_panel` | 기존 수식의 고점 구간·고점일·목표 우선 도달·비용 후 손익 비교 | 실제 시점 보존 검증이나 수익성 입증으로 자동 승격하지 않는다. |
| 5 | `panel_job`·`panel_report` | 중단 재개·요청 상한·산업/기간/변동성/거래대금별 집계·한국어 설명 | 마지막 기간과 별도로 보관한 기업의 결과는 실행하지 않는다. |

산업군당 **서로 다른 기업 100개**가 목표다. 동일 CIK의 여러 주식 종류는 한 기업으로 세며 분류가 충돌하면 제외 이유를 남긴다. 모든 명부·분류 확인을 처리한 뒤 가격 성적을 보기 전에 표본을 고정한다. 분류가 미확인인 기업도 별도 목록에 보존한다. 확인된 기업이 100개 미만인 산업군은 ‘부족’이며 임의로 합치거나 성공으로 표시하지 않는다. 약 20% 기업은 처음 보는 기업에 대한 마지막 시험용으로 남긴다. 이미 살펴본 BE 기업은 그 집단으로 세지 않는다.

완전한 이력은 공통 거래일 기준 개발 50개·중간 확인 16개·마지막 시험 16개 기준일로 나뉜다. 이번 자동 작업은 앞의 66개만 실행한다. 다음 5거래일이 구간 경계를 넘는 기준일은 버린다. 거래일이 누락되거나 기업 식별이 맞지 않으면 해당 기업의 가격 검사를 보류한다. 가격이 일찍 끝난 기업은 확인 가능한 구간만 계산하고 이후 정답이 없는 기준일은 미해결로 센다.

## 실제 실행 상태를 어디서 보는가

2026-11-08 등록·시작한 작업은 `Stocker-HistoricalPanel-58488d99d05b4d1e`이며 폴더는 `reports/private/historical_panel/58488d99d05b4d1e/`다. [재검토·착수 결과](HISTORICAL_PANEL_REVIEW_20261108.md)에 초기 확인 수와 검사의 의미를 기록했다. 완료 시각과 표본 수는 수집 진행 결과로 확인한다.

`reports/private/historical_panel/<job_id>/`에 저장한다. `$jobFile`에는 해당 폴더의 `job.json` 절대 경로를 넣는다.

- `STATUS.ko.md`: 초보자를 위한 현재 단계·수집 수·미확인 수·100개 조건·다음 확인 내용. 작업이 진행될 때 갱신한다.
- `progress.json`·`state.json`: 실제 네트워크 요청량과 재개 위치. 표본 선정 전의 목표 수를 평가 완료 수로 표시하지 않는다.
- `catalog.json`·`profiles/`·`cohort.json`: 과거 명부, 식별/분류 결과와 고정한 기업 목록. 표본 고정 전에는 `cohort.json`이 없다.
- `prices/`: 공급자 원본·실제 조회 시각·정규화 가격·마지막 가격일의 기업 식별 자료. 외부 LLM에 입력하지 않는다.
- `evaluation/`: 기업별 입력/코드 해시, 기준일별 원본 계산과 결과, 개발/중간 구간 집계.
- 완료 후 `REPORT.ko.md`·`panel_result.json`: 결과 의미와 산업군별 표, 월/구간/사전 변동성/거래대금별 세부 집계. 수익 수치는 개인용 로컬 파일에만 둔다.
- `integrity_failure.json`: 코드·설정·원천 자료 해시가 달라져 멈춘 경우. 완료한 과거 결과를 새 계산으로 덮어쓰지 않는다.

```powershell
.\.venv\Scripts\python.exe -B -m research.panel_job --job $jobFile --status
.\.venv\Scripts\python.exe -B -m research.panel_job --job $jobFile --check
```

첫 명령은 키·가격·수익률을 출력하지 않고 건수와 상태만 보여준다. `--check`는 작업에 고정한 코드·설정·원천 자료 해시를 확인한다. 연구 규칙을 바꾸면 진행 중 작업을 덮어쓰지 않고 별도 작업을 등록해야 한다. 문서와 관련 없는 새 모듈은 기존 계산을 바꾸지 않고 개발할 수 있다.

## 무료 API와 백그라운드 동작

별도 작업 이름은 `Stocker-HistoricalPanel-<job_id>`다. `pythonw.exe`로 창을 열지 않고 실행하며, 5분마다 실행 기회가 있고 중복 실행은 무시한다. 한 번에 최대 20분 또는 평가 기업 20개를 처리한 뒤 저장한다. PC를 끄거나 로그아웃하면 실행할 수 없으며 다음 로그인/사용 가능 시점에서 재개한다. 암호를 저장하거나 관리자 권한으로 실행하지 않는다.

가격·분류 요청은 캐시와 최소 15초 간격을 공유한다. 429 제한 응답은 공급자의 `Retry-After`를 따르고, 없으면 15분 대기한다. 한 기업의 일시 실패는 최대 3회만 처리하며, 권한 없음·키 없음·정해진 한도 도달은 중단한다. 키는 Windows 사용자 환경변수 `MASSIVE_API_KEY`에서 읽고 파일·작업 인자·상태 출력에 저장하지 않는다.

전체 한도는 **실제 요청 16,000회 또는 첫 실행부터 96시간**이다. 완료·확인 불가·한도 도달 시 이 작업만 자동 비활성화한다. BE의 기존 `Stocker-BE-Outcome-4075ad8deab9133e`는 변경하지 않는다. 오래 꺼져 있어 수집이 끝나지 못한 경우도 한도 도달 상태로 남기며 완료로 바꾸지 않는다.

12개 산업군이 모두 기업 100개 조건을 만족하면 최대 1,200개 기업을 고른다. 가격 1회와 마지막 가격일의 기업 식별 1회를 기업마다 요청하면 최대 2,400회다. **전 명부의 산업 코드를 확인하는 요청은 이와 별도**라 가장 많은 시간이 든다. 최소 15초 간격 기준 명부 분류 대상 기업 수를 `N`이라고 하면 단순 API 간격 하한은 `(명부 페이지 수 + N + 최대 2,400) × 15초`이며 응답 시간·재시도·작업 사이 대기는 별도다. 보통 수시간 내 전체 완료를 약속할 수 없다. 유료 전환 없이 기다리며, 외부 LLM 호출·토큰은 0이다. [무료 플랜 범위](https://massive.com/stocks).

새 작업 준비와 등록은 다음과 같다. `--definition-source`에는 직접 받은 FF12 정의 파일을 재사용할 수 있다. 생략하면 공식 ZIP을 한 번 받는다. 계정 확인을 다시 수행하거나 유료 플랜을 활성화하는 명령이 아니다.

```powershell
.\.venv\Scripts\python.exe -B -m research.panel_job --prepare --definition-source $definitionFile
.\scripts\install_panel_task.ps1 -JobFile $jobFile
```

## BE 실행 확인과 남은 평가

`reports/private/historical_panel_pilot/20261107T165029073340Z/REPORT.ko.md`에 실제 BE 가격의 66개 기준일 실행 확인을 저장했다. 기존 가격을 다시 사용했고 마지막 가격일 식별 조회만 1회 새로 요청했다. 계산 미해결 0건, 마지막 시험 실행 0건, 학습/튜닝/LLM 호출 0건이다. **BE는 이미 살펴본 종목이므로 이 실행을 새 기업이나 다른 산업의 예측력 입증으로 세지 않는다.**

대규모 수집이 끝나면 먼저 산업군별 100개 조건, 가격 누락·상장폐지 처리, 계산 가능한 비율과 비용 후 수익 범위를 본다. 같은 날짜 주식들의 동반 움직임을 보존한 날짜 묶음의 불확실성 계산은 후속 단계다. 무료 약 2년의 조회 범위로 장기·하락장 전반을 대표한다고 주장하지 않는다. 개선 후보와 비교 기준을 따로 등록한 뒤에야 잠근 기업·마지막 기간의 시험을 논의한다. 현재 추천 점수와 수익성 승인 값은 비어 있다.
