# 그 시점에 알 수 있었던 뉴스만 보관·조회하기

이 기능은 향후 뉴스가 예측에 도움이 됐는지 비교할 준비 작업이다. 나중에 나온 기사나 수정된 제목을 과거 판단에 섞으면 예측이 실제보다 좋아 보일 수 있다. 이를 막기 위해 메타데이터의 보관 시각과 내용 버전을 함께 쌓는다.

## 무엇을 기록하는가

제목·원문 링크·출판사·공급자가 표기한 발행 시각을 내용 버전으로 구분한다. 수집 출처·관측 시각·관련 주제와 뉴스 검색의 확인 수준도 당시 묶음으로 보관한다. 본문·요약·이미지·공급자 감정 판정은 저장하지 않는다. 내용 변경은 ‘새로운 사실을 확인했다’는 판정이 아니며 원문 검토를 기다린다.

처음 보관한 시각부터 그 버전을 사용할 수 있다고 취급한다. 이전에 내려받은 자료라도 오늘 처음 보관했다면 공급자의 과거 발행일로 가용 시각을 소급하지 않는다. 원래 다운로드 시각은 별도로 남긴다. 같은 내용을 재수집하면 최초 보관 시각과 내용 파일을 유지하고 새 관측 묶음만 추가한다. 같은 입력을 재보관하는 것은 중복으로 처리한다.

예를 들어 오전의 제목 A가 오후에 B로 바뀌었다면 오전 조회에는 A만 나온다. 이후 A로 다시 바뀐 실제 관측도 기록한다. 같은 초에 여러 번 저장한 경우의 순서를 보존한다. 미래 버전의 내용을 먼저 선택하거나 원본 발행일이 오래됐다는 이유로 미래 수정을 과거에 끌어오지 않는다.

## 실제로 무엇을 확인했는가

2026-11-07 **22:51:01 한국 시간**에 기존 BE 관련 링크 1건과 EIA 공식 링크 3건, 총 4건의 메타데이터를 처음 보관했다. 최초 보관 직전인 22:51:00 조회는 0건, 최초 보관 시각의 조회는 4건이었다. 같은 자료를 다시 보관했을 때 새 내용 버전은 0건이었고 최초 보관 시각도 유지됐다.

이 0→4는 과거로 자료를 소급하지 않는 기능이 작동했다는 뜻이다. 뉴스의 유용성이나 주가 예측력이 확인됐다는 뜻은 아니다. 네 링크의 실제 사건·BE 영향 검토도 아직 남아 있다. 당시 확인하지 못한 뉴스 주제는 계속 미확인으로 보관하며 중립으로 바꾸지 않는다.

원래 뉴스 확인 시각과 아카이브 시각은 서로 다르다. 조회 결과는 원래 확인 시각도 보여주며 30분을 넘긴 자료를 현재 뉴스로 표시하지 않는다. 가상 예제는 별도 공간에 보관해 실제 검증 자료와 섞이지 않게 한다.

## 실행 방법

Stocker 가상환경에서 실행한다. 이 명령들은 저장된 자료만 읽으며 새로운 네트워크 요청을 하지 않는다.

```bash
python -m research.news_archive
python -m research.news_archive --as-of "2026-11-07T22:51:00+09:00"
```

첫 명령은 가장 최근 `evidence_context.json`을 보관한다. 다른 근거 파일을 지정하려면 `--context <경로>`를 사용한다. 둘째 명령은 해당 시각까지 실제 보관된 자료만 조회한다. `--as-of`는 읽기 전용이며 과거 날짜로 저장하는 기능이 아니다. 가상 자료 조회에는 `--illustrative`를 사용한다.

기본 저장 위치는 `reports/private/news_archive/`이고 실제 자료는 `real/`, 가상 자료는 `illustrative/`다. `versions/`에는 내용 버전, `captures/`에는 당시 묶음을 추가한다. 묶음 저장이 완료돼야 조회 대상으로 삼으며 원본 내용 해시와 파일 경로를 검사한다. 조회 결과는 `reports/private/news_archive_views/`에 저장한다.

원문·사용권·코드의 해시와 출처를 남기지만 로컬 파일의 기록이 독립된 시각 인증이나 사용권 진위의 증명은 아니다. 실제 보관·조회에는 해당 출처의 현재 메타데이터 사용권도 확인한다. 보관 기능은 ML 학습권을 부여하지 않으며 추천 점수도 계산하지 않는다. 기존 가격·비용 사전 기록과 예약 작업은 변경하지 않았다.

정책은 `config/news_archive_policy.json`, 계약은 `schemas/news_archive.schema.json`이다. 다음에는 검토한 사건 이력과 사전 가격 예측을 시점에 맞게 연결해, 같은 평가 사례에서 뉴스 포함/미포함의 추가 기여를 비교할 수 있다. 그 비교를 실제로 수행하기 전에는 효과가 있다고 설명하지 않는다.
