# 섹터별 다종목 과거 검증을 주 경로로 전환

2026-11-08 사용자 제안을 반영한 우선순위 변경이다. **함수의 정밀도 개선과 범용성 확인은 여러 종목·여러 시기의 과거 검증을 주 경로로 삼는다.** BE 한 종목의 5거래일 자동 관찰은 고정한 예측을 이후 실제 제공 자료와 비교하는 보조 전진검증으로 유지한다. 그 한 건으로 함수를 자동 튜닝하거나 성능을 승인하지 않는다.

이미 BE 과거 가격 진단과 합성 시장 실험을 수행했다. 부족한 것은 실제 여러 종목·섹터·시장 상황의 범위다. 11월 14일의 첫 관찰 결과를 기다리는 동안에도 과거 자료로 개발을 진행할 수 있다.

## 같은 함수로 어떻게 평가하는가

과거의 기준일마다 그날까지의 가격만 함수에 넣고, 다음 5거래일의 고점·목표 후보·도달 시기를 계산한다. 이후 실제 5일 가격으로 예상 고점이 얼마나 가까웠는지, 목표보다 손실 기준에 먼저 닿았는지, 비용을 빼고 수익이 남았는지를 비교한다. 차트 이미지를 읽는 대신 시가·고가·저가·종가·거래량 수치를 사용한다.

첫 단계에서는 기존 고정 통계 함수와 수식을 바꾸지 않는다. 충분한 종목에서 현재 함수의 약점을 확인한 뒤 별도 후보 버전으로 개선한다. 실제 ML 모델의 훈련은 데이터의 학습 사용권을 확인한 다음에 연결한다. 과거 재생과 학습형 모델 훈련의 사용 조건을 같은 것으로 취급하지 않는다. [개인용 분석과 AI/ML 사용 조건](https://massive.com/legal/market-data-terms-of-service).

## 표본과 분할 기준

- 섹터당 최소 100종목을 목표 조건으로 유지한다. 해당 분류에서 실제로 조건을 만족하는 종목이 100개 미만이면 부족으로 표시한다. 종목 수나 자료 부족을 통과로 바꾸지 않는다.
- 섹터 분류와 종목 집단은 결과를 보기 전에 고정한다. 현재 살아남은 인기 종목만 고르지 않고, 당시 상장됐다가 이후 사라진 종목도 확인한다. 과거 기준의 분류·상장 상태를 입증하지 못하면 그 한계를 표시한다.
- 모든 종목에 공통된 날짜 기준으로 개발 60%, 검증 20%, 최종 평가 20%를 나눈다. 같은 시기의 A종목은 학습, B종목은 평가가 되도록 무작위로 행을 섞지 않는다.
- 튜닝은 개발·검증 구간에서 수행하며 최종 평가 결과는 후보와 기준을 고정할 때까지 열지 않는다. 이미 여러 차례 결과를 본 BE는 새 종목 일반화 평가의 미관측 종목으로 세지 않는다.
- 5일 결과 창이 다음 구간으로 넘어가는 기준일은 제거한다. 서로 겹치는 5일 사례와 같은 시장 충격을 받은 종목 수를 모두 독립 표본으로 세지 않는다.
- 섹터별 일부 종목은 전역 파라미터 선택에서 제외해 새로운 종목에서도 작동하는지 별도로 비교한다.

튜닝에 사용한 과거 성적을 그대로 최종 성능으로 제시하면 과적합이 생길 수 있다. 여러 설정을 시험한 이력과 실패도 남기며, 마지막 구간을 보고 다시 설정을 고른 경우 더 이상 미관측 최종 평가라고 부르지 않는다. [백테스트 과적합 원 논문](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf).

## 어떤 결과를 볼 것인가

| 질문 | 평가할 내용 |
|---|---|
| 고점을 잘 예상했는가? | 예상 고점 구간의 포함률과 실제 고점 오차. 종목 가격대가 달라도 비교할 수 있도록 최근 변동폭 단위도 사용한다. |
| 시기를 잘 예상했는가? | 고점 형성일과 목표 우선 도달일의 오차·누락. 두 날짜를 같은 것으로 취급하지 않는다. |
| 실제로 이익을 남길 조건인가? | 매수·매도 비용 후 손익, 손실 분포, 목표보다 손실 기준에 먼저 닿은 비율. |
| 간단한 방법보다 나은가? | 같은 기간 단순 보유, 기존 고정 기준과 같은 사례·비용으로 비교한다. |
| 특정 구간에서만 좋아 보이는가? | 섹터·기간·변동성·유동성별 결과와 실패·보류·거래하지 않음의 횟수를 함께 본다. |

같은 일봉에서 목표와 손실 기준에 모두 닿으면 어느 쪽이 먼저인지 알 수 없으므로 손익 범위를 남긴다. 상장폐지·기업행동·자료 누락으로 결과를 모르면 미해결로 기록하며 유리한 0 수익으로 채우거나 몰래 제외하지 않는다. 가정한 비용·체결 규칙의 가상 손익을 실제 계좌 수익으로 표현하지 않는다.

## 우선 가격 모듈부터 평가한다

현재의 뉴스나 최근 공시를 과거 시점에 넣으면 미래 정보를 사용한 결과가 된다. 따라서 첫 대규모 재생은 고점·기간·거래 비용 모듈을 가격만으로 평가한다. 재무·뉴스를 더한 모형은 당시 공개 시각과 검토 이력이 있는 자료를 확보한 뒤 같은 사례에서 추가 기여를 비교한다.

현재 내려받는 과거 가격도 나중에 정정·분할 조정된 조회본이다. 날짜순으로 계산하더라도 과거 원본이 완전히 보존된 자료라고 자동 승격하지 않는다. 이 한계는 과거 검증을 하지 않을 이유가 아니라, 결과의 해석 범위와 보조 전진검증을 함께 두어야 하는 이유다.

## 무료량과 실행 규모

[현재 Massive Stocks Basic](https://massive.com/stocks)은 2년 이력과 분당 5회 요청을 제공한다. 11개 섹터에서 100개씩 확보한다고 가정하면 1,100종목이고, 종목당 가격 이력을 한 번씩 요청하는 데만 한도상 최소 약 220분이 필요하다. 종목 식별·분류·페이지 조회·응답 시간·재시도는 별도다. 이는 용량 예시이며 실제 11개 섹터 집단을 선정했다는 뜻이 아니다.

한 번 저장한 가격으로 여러 과거 기준일을 로컬에서 반복 계산하므로 기준일마다 API를 다시 부를 필요는 없다. 현재 수치 계산의 LLM 호출·토큰은 0이다. 따라서 큰 과거 검증 자체가 유료 플랜이나 LLM 호출을 필수로 만들지는 않는다. 무료 2년의 시간 범위로는 다양한 장기 시장 국면을 충분히 덮지 못할 수 있으므로 긴 이력의 적법한 무료 원천도 병행 검토한다.

## 준비 계산과 실제 실행을 구별한다

`config/historical_evaluation_protocol.json`에 위 기준을 등록하고 `research.historical_preflight`로 공통 거래일 분할·5일 경계 제거·API 용량을 계산했다. 완전한 480거래일 이력의 종목이라는 가정에서 개발 50·검증 16·잠근 최종 평가 16개 기준일을 계획했다. 이는 실제 가격 성적이 아니며 유효한 데이터가 없는 종목에서는 달라진다.

2026-11-08 재검토 후 `panel_transport`·`sector_universe`·`panel_prices`·`historical_panel`·`panel_job`을 별도로 구현했다. 기존 BE·SPY·PBW 수집기의 제한과 BE 예약 계산 원본은 보존한다. 새 실제 BE 실행은 개발 50·중간 확인 16개 기준일을 완료했으며 마지막 시험 16개는 실행하지 않았다. 이 66건은 실행 경로 확인이며 섹터 표본의 성능 결과가 아니다.

실제 산업 분류는 [공개 FF12 SIC 범위](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/Siccodes12.zip)를 사용한다. 원래 Fama–French 포트폴리오나 수익률을 복제한 것이 아니며 GICS로 표기하지 않는다. 2024-12-09 명부에서 미국 일반주·지원 거래소·발행사/주식 식별이 확인된 기업을 대상으로, 같은 CIK 기업의 여러 주식 종류를 한 기업으로 묶고 결과와 무관한 해시 순서로 산업군당 100개를 고정한다. BE의 발행사 식별자는 미관측 기업 평가에서 제외한다. 산업군당 약 20% 기업은 마지막 시험 전용이다.

당시 상장 여부를 요청한 종목 명부와 SIC 조회는 현재에 받은 과거 기준 응답이다. 공급자는 일부 상세 금융 필드에 보고기간 기준 값이 포함될 수 있음을 설명한다. 재무 필드는 입력에서 제외하며 SIC의 역사적 원본 상태도 입증됐다고 주장하지 않는다. [상세 조회의 날짜 정의](https://massive.com/docs/rest/stocks/tickers/ticker-overview), [과거 명부 조회](https://massive.com/docs/rest/stocks/tickers/all-tickers).

표본은 모든 명부 페이지와 분류 확인을 처리한 뒤 가격 성적을 보기 전에 고정한다. 확인 실패 목록도 보존한다. 가격 이력이 일찍 끝나는 기업도 마지막 가격일의 발행사·주식 식별을 확인해 가능한 구간을 평가하고, 이후 5일이 없는 기준일은 미해결로 남긴다. 식별 충돌·거래일 누락 등으로 가격 전체를 확인하지 못하면 다른 기업으로 교체하지 않는다.

기본 수식의 변경·학습·정밀도 튜닝과 미관측 최종 시험은 이번 작업 범위에 넣지 않는다. 날짜·산업·종목·사전 변동성·거래대금별 결과, 고점 오차·목표/손실 우선 도달·비용 후 손익 범위를 저장한다. 불확실성의 범위는 같은 날짜의 여러 기업이 함께 움직이는 특성을 반영해 후속 검토해야 하며, 건별 평균을 계좌 누적 수익률로 표현하지 않는다. 자동 작업과 결과 위치는 [실행 안내](HISTORICAL_PANEL_RUNBOOK.md)에 있다.

```bash
python -m research.historical_preflight
```

이 명령은 준비 계산만 수행한다. 네트워크 요청·실제 종목 평가·모델 학습은 0이며 최종 평가 성적이나 추천 점수를 출력하지 않는다.
