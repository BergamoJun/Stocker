# 무료 학습 데이터 추가 검토 — 2026-11-07

범위는 개인 로컬 미국 주식, 월 $0, 실제 BE 5거래일 OHLCV 학습과 보존이다. 후보 목록은 `config/model_training_sources.json`에 기록한다. 후보 문서는 권한 활성화 기록이 아니다. 이번 검토에서 실제 학습용 가격을 내려받거나 계정을 생성·유료 전환하거나 공급자에게 메시지를 보내지 않았다.

## SimFin: 추가로 확인한 근거와 남은 조건

[데이터 라이선스 §1](https://www.simfin.com/en/commercial-license/)은 FREE/BASIC의 개인 연구 사용을 명시한다. §4는 소프트웨어를 이용한 재가공을 허용한다. [공식 튜토리얼](https://github.com/SimFin/simfin-tutorials)에는 Machine Learning과 Neural Networks 예제가 있다. 따라서 개인 ML에 관한 공식 근거가 전혀 없는 상태라고 설명하면 부정확하다.

다만 [일반 약관](https://www.simfin.com/en/legal-advice/)은 IEX 제공 시장 데이터에 별도 원천 약관을 적용한다. 연결된 `https://iextrading.com/api-exhibit-a/`는 `https://iexcloud.io/terms/`로 이동하며 이번 조회 도구에서는 본문을 읽을 수 없었다. 그 상태에서 실제 가격 원천 조건까지 충족했다고 확정하지 않았다. 근본주의적인 모든 AI 금지로 판단한 것도 아니다.

[무료 플랜](https://www.simfin.com/en/prices/)은 5년 차트/재무 이력과 API/일괄 다운로드를 안내한다. 이 안내만으로 실제 BE의 무료 OHLCV 행 수, 지연 기간, 분할 조정 방식, 현재 계정에 적용되는 조건을 확정하지 않는다. [공식 Python API](https://github.com/SimFin/simfin)는 본인 API 키를 위해 무료 가입이 필요하다고 안내한다. 무료 플랜 유지/종료 시 저장 자료 사용 조건도 확인해야 한다.

현재 상태는 **개인 연구 허용·공식 ML 예제 확인, 실제 BE 가격 원천·범위·계정 조건 미확정**이다. 기존 Massive 개인 권한을 SimFin에 전용하거나 `model_training=allowed`로 임의 변경하지 않는다.

## EODHD: 무료 이력의 부족

[공식 요금표](https://eodhd.com/pricing)는 무료 20회/일, 20회/분, EOD 과거 1년을 명시한다. [약관](https://eodhd.com/financial-apis/terms-conditions)은 개인 저장·가공·분석을 허용하며 [홈페이지](https://eodhd.com/)는 ML 워크플로를 설명한다. 이것만으로 플랜/원천별 학습 조건 검토를 마친 것은 아니다.

무료 1년은 현재 단일 종목의 학습·오차 추정·최종 평가 표본 조건을 충족하기에 부족하다. 공급자 안내는 비거래소 집계·참고 가격일 수 있다고 명시하므로 실제 거래가격·고저가 도달 평가 적합성도 검토해야 한다. 유료 이력을 활성화하지 않는다. 현재 실제 BE 학습 경로로 선정하지 않았다.

## 실행 가능한 후속 조건

1. SimFin 실제 무료 BE 일봉 범위·조정·지연·보존 조건과 해당 원천 조건을 확인한다.
2. 해당 자료에 적용되는 개인 수치 ML 학습 허용을 검토 기록으로 남긴다. 접근 불가인 원천 문서나 계정에만 보이는 조건은 미확인으로 유지한다.
3. 허용 이력으로 학습/오차 추정/평가 표본 수를 계산하고 부족하면 더 긴 무료 허용 이력 또는 사전 정의한 다종목 학습 집단을 검토한다.
4. 현재 데이터 공급자에서 받은 명시적 추가 허용도 가능하다. 문의 초안은 [LEARNED_PEAK_MODEL.md](LEARNED_PEAK_MODEL.md)에 준비되어 있으나 전송하지 않았다.

새 공급자/사용 범위를 확정하기 전 실제 BE 지도학습은 대기 상태다. 무료 API가 존재한다는 사실과 이번 목적의 자료·권한·표본이 충분하다는 판단을 분리한다.
