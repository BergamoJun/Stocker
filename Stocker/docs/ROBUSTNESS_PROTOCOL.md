# 같은 잡음·거래량 제외·다중 시드 후속 검증

후속 검증 정책은 `config/robustness_protocol.json`의 `learned-peak-matched-robustness-v1`이다. 모델 계수/가중치/기존 정책 파일은 실험 결과에 맞춰 조정하지 않는다. **모든 자료는 ILLUSTRATIVE — NOT LIVE MARKET DATA이며 실제 BE 학습은 수행하지 않는다.** 기존 합성 실험의 미관측 구간을 새로운 미관측 검증으로 재사용하지 않는다.

완료한 실험 결과와 진행 방향: [ROBUSTNESS_RESULTS_20261107.md](ROBUSTNESS_RESULTS_20261107.md).

## 사전 고정 조건

새 난수 시드 77011/77023/77041, 각각 합성 일봉 1,100개를 사용한다. 기본 일간 잡음 표준편차는 모두 0.006이다. 같은 시드의 각 시장은 같은 일자에 같은 표준정규 난수를 사용한다. 신호 크기 0/0.5/1 시장은 방향 성분의 크기만 다르게 설정한다. 거래량은 기존과 같이 신호에 연결되므로 거래량 포함/제외를 같은 경로에서 별도로 비교한다.

시장 5종은 신호 없음, 약한 신호, 강한 신호, 최종 평가 시작 직후 신호 부호 반전, 같은 시점 잡음 3배 증가다. 스트레스 시작은 첫 평가 기준일의 다음 세션이다. 그 이전의 학습·오차 추정 구간은 강한 신호 시장과 동일하다. 급변은 의도적인 분포 변화 검사이며 같은 잡음 비교의 대조군과 구분한다.

각 데이터셋에서 거래량 포함 8개 특징과 제외 7개 특징으로 각각 학습한다. 제외한 특징은 표준화·계수·지원 범위 검사에도 사용하지 않는다. 입력 계약은 8개를 보존하며 제외한 열 및 제곱항은 계산에서 0으로 처리한다. 나머지 학습 규칙은 기존 Ridge 정책 그대로다. 5시장×3시드×2특징 구성이 총 30개 학습 실험이다.

## 공정한 비교와 보류

기존 EWMA와 무조건부 학습 구간 분포는 데이터셋별로 한 번 계산해 두 변형에서 공유한다. 각 데이터셋에서 거래량 포함/제외, EWMA, 무조건부 분포가 모두 예측한 기준일의 교집합으로 오차를 비교한다. 각 모델의 전체 예측 가능/보류 수와 공통 사례 수를 함께 표시한다. 기준선 캐시는 입력 경로 해시가 다른 자료에 재사용하지 않는다.

EWMA는 매 기준일까지의 과거로 통계를 갱신하며 Ridge 계수·잔차는 고정 학습/오차 추정 구간에서만 산출한다. 이 갱신 정책의 차이를 숨기지 않는다. 급변에서 어려운 사례가 보류되어 공통 모집단이 줄면, 남은 사례의 낮은 오차를 전체 시장에서의 개선으로 주장하지 않는다.

고점 MAE, 분위 오차, 가격 구간 포함 빈도, 고점 구간×고점일 Brier, 고점일 오차를 비교한다. 시드별 평균을 같은 비중으로 집계하고 학습 MAE−EWMA MAE의 시드 범위와 개선 시드 수를 보고한다. 세 시드 결과에 유의성·일반화 확률을 붙이지 않는다.

## 체결·목표 도달기간

편도 10/25bp 비용, 다음 시가 진입, 최대 5세션 관찰을 재사용한다. 양의 매매 계획이 없거나 시가가 목표/무효화 밖이면 신규 진입 없이 현금 수익 0으로 처리한다. 이는 후속 프로토콜에 사전 명시한 규칙이며 기존 진단의 제외 집계를 변경하지 않는다.

동일 일봉 목표/무효화 동시 도달은 가능한 무효화 체결~목표 체결의 비용 후 손익 경계로 남긴다. 선후를 추정하지 않는다. 동일 공통 예측 사례에서 현금·모호성까지 포함한 평균 손익 하한/상한과 결과별 건수를 집계한다. 모델 미지원 입력은 현금 0으로 바꾸지 않고 예측 보류로 별도 표시한다.

목표 우선 도달의 관측 빈도 역시 동시 도달을 포함한 하한/상한이다. 목표가 먼저 도달한 사례에서만 예측 기간 범위의 중간값 오차와 포함 빈도를 측정하고, 기간 추정이 없는 목표 도달 사례도 별도로 센다. 이는 예측 고점일의 오차와 다르다. 세션이 다른 목표를 가진 전략끼리 관측 빈도를 같은 사건의 확률처럼 비교하지 않는다.

## 실행·보존

```powershell
./.venv/Scripts/python.exe -B -m research.robustness
```

실제 가격 파일 인자를 받지 않는 합성 전용 CLI다. 결과 계산 전에 정책·코드 해시와 전체 계획을 기록한다. 15개 데이터셋의 진행 파일, 30개 개별 결과, 전체 요약을 ignored `reports/private/robustness/<시각>/`에 새로 저장한다. 현재 소스가 바뀌어도 등록한 코드로 결과를 추적할 수 있게 `registered_sources/`에 해시와 일치하는 실행 소스도 보존한다. 파일 덮어쓰기나 실험 중 매개변수 조정을 하지 않는다.

JSON 계약은 `schemas/robustness.schema.json`이다. 누락·중복 실험, 실제 데이터 표기, 추천 점수/검증 승인 값은 거절한다. 실패한 실험도 기록하며 성공한 결과만 선택하지 않는다. LLM 호출·토큰·데이터 구매 비용은 0이다.

## 다음 결정

이 검사는 합성 민감도 검사다. 기존 통계 모형 교체·새 회귀 파라미터 선택·추천 점수 활성화의 근거로 사용하지 않는다. 실제 BE 학습권, 충분한 허용 이력, 시점 보존 평가·전향 기록을 확보한 뒤 실데이터에서 비교한다. 데이터 권한 조사 결과는 [TRAINING_DATA_REVIEW_20261107.md](TRAINING_DATA_REVIEW_20261107.md)에 기록한다.
