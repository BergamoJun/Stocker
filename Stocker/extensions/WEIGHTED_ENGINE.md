# 자동 가중 분석 엔진 v1

종목의 현재 저장 입력을 읽어 23개 변수의 가산·감점, 조건부 사업 경로, 반론과 누락을 자동 작성하는 개인용 연구 엔진이다. `weighted_features`가 숫자를 계산하고 `weighted_events`가 허용 공식 문구를 추출하며 `weighted_critic`이 출처·계수·합산·누락·비용/위험을 검사한다. 사람의 기사별 판단 파일을 정상 실행의 필수 조건으로 두지 않는다.

이번 엔진의 사업·사건 해석은 **로컬 고정 규칙의 제한된 문구 추출과 조건부 경로**다. 외부 AI의 자유 추론, 학습형 인과효과 추정이나 모든 기사에 대한 의미 판독을 구현했다고 표시하지 않는다. 임의 언론사 본문·주가를 외부 AI에 보내거나 유료 API를 활성화하지 않는다.

## 중요도 계수

기존 고점 모델의 축별 예산 25/15/10/10/40을 유지하고 별도 정책에서 세분화했다. 계수는 설계 가정이며, 데이터로 학습한 회귀 계수·경험적으로 입증된 중요도·성공 확률이 아니다. 기존 `peak_model_policy`와 다른 과거 후보의 계수·계산·결과는 바꾸지 않는다.

| 축 | 합계 | 세부 변수와 계수 |
|---|---:|---|
| 수익 기회 | 25 | 비용 후 목표 후보 여력 10, 보수적 모형 손익 7, 비용 후 손익비 5, 모형 고점 집중도 3 |
| 가격·거래량 | 15 | 20일 평균 대비 추세 4, 20·60일 평균 배열 3, 변동폭 대비 5일 변화 4, 거래량 방향 확인 2, 급등 이격 감점 2 |
| 기업 실적·재무 | 10 | 영업 수익성 3, 원문 기간 FCF 부호 2, 총부채 대비 현금 2, 자산 대비 총부채 2, 순손익 부호 1 |
| 시장·업종 | 10 | 시장 추세 3, 업종 추세 3, 시장 대비 상대 변화 2, 업종 대비 상대 변화 2 |
| 최신 사건 | 40 | 회사 12, 업종 8, 거시·금리 10, 원자재 6, 정치·정책 4 |

정확한 정규화·앵커·범위는 [weighted_policy.json](weighted_policy.json)에 고정한다. 예를 들어 비용 후 여력 5%, 모형 손익 2%, 영업이익률 20%, 상대 변화 5%p는 실증 보정 전 앵커다. 다른 기업/업종에 최적이라고 주장하지 않는다. 자산·부채는 결산일 잔액, 현금흐름은 원문 기간 누적, 순손익은 지배기업/연결 귀속 범위를 유지한다. 총부채 비율을 차입금 비율이나 유동비율로 부르지 않는다.

## 합산과 자료 부족

각 값 `x_i`를 -1~1로 정규화하고 `p_i = w_i*x_i`로 가감점한다. 이격 변수는 -1~0의 감점만 가진다. 모든 값이 있을 때 연구 지수는 `round_half_up(clip(50 + Σp_i/2, 1, 100))`다. 50은 산식의 중심일 뿐, 자료가 없을 때 출력하는 기본 점수가 아니다. 이격 감점의 한쪽 범위 때문에 현재 설계의 산술 상한은 99다.

하나라도 없으면 `experimental_score=null`이며 나머지 가중치를 확대하지 않는다. 확인한 합과 각 미확인 값의 허용 범위로 `completion_score_bounds`를 계산한다. 이 범위는 **부족한 변수가 달라질 때의 산술 범위**이며 예측 구간·신뢰구간이 아니다. `observed_weight`도 자료 충족 계수 합이며 투자 확신이나 승률이 아니다. `released_score`, 가격 계획, 수익 실현 시기와 검증 ID는 정식 승인 전까지 제공하지 않는다.

## 미래 모형·가격

원본·사용권·현재 EOD·연속 거래일을 확인한 다음 기존 `peak_simulation.forecast`를 그대로 호출한다. 512개의 5거래일 고정 EWMA·Gaussian/bridge 경로는 실제 관측 거래 512건이 아니다. 비용은 주로 편도 25bp 시나리오를 사용하고 목표·무효화 양쪽 도달 순서의 손익 하단을 보수적으로 쓴다. 그 하단은 통계적 신뢰 하한이 아니다. 기존 비용/위험 필터 실패를 다른 가점으로 해제하지 않는다.

가격·ETF·통화·조정·같은 거래일, 최소 60개 일봉, 모형이 읽는 최근 최대 253개 연속 세션을 검사한다. 현재 완료 세션이 없으면 가격 요소를 보류한다. 생성 시각과 사용 자료의 기준시각은 별도이며 오늘 만든 계산을 과거에 존재한 예측으로 기록하지 않는다. 이전 BE 관찰·산업별 평가·SEC 갱신 작업이나 예측 원장을 호출·수정하지 않는다.

## 최신 사건·반론

연준의 결정 문구와 EIA의 에너지 문구를 허용 문단에서 찾고 기업별 자금조달·수요·전력·연료/투입비용 경로 및 반론을 기록한다. 사건 원문 주소와 정확한 문단 인용을 연결한다. 이는 가격 인과효과나 향후 5세션 영향의 인증이 아니다. 금리와 자산 가격에는 여러 전달 경로와 시장 기대가 작용한다. [연준의 전달 경로 설명](https://www.federalreserve.gov/monetarypolicy/monetary-policy-what-are-its-goals-how-does-it-work.htm).

새로운 자료를 호재로 간주하지 않는다. 서명된 영향에 `1 + 2^(-최초공개 후 경과시간/24시간)`을 곱해 최신 호재·악재의 크기를 동일하게 높인다. 같은 사건은 최초 공개 시각으로 묶고 중복 기사·주제 간 중복·상반된 판독을 검사한다. 날짜만 있는 원문, 미확인 방향·시장 기대·단기 관련성은 수치 반영을 보류한다. 정치 위험을 거시 문서로 대체하거나 에너지 문서 몇 개를 전체 원자재 취재 완료로 간주하지 않는다.

현재 공식 원문 입력은 제한된 문서 집합이다. 뉴스 5개 축에 완전한 72시간 범위의 수집·자동 판독 증거가 없으면 해당 가중치는 보류한다. `automatic_supported_event`와 `bounded_verified` 인터페이스는 이후 검증된 자동 판독·수집기가 제공할 구조이며 현재의 문구 후보를 그 상태로 승격하지 않는다. 사용자에게 수동 해석을 요구해서 빈칸을 채우는 경로는 기본 흐름에 추가하지 않는다.

## 파일·실행·검증

```powershell
.\.venv\Scripts\python.exe -B -m extensions.weighted_engine --baseline reports/private/weighted_engine_case/20261109/runtime.json --ticker BE
.\.venv\Scripts\python.exe -B -m extensions.weighted_engine --baseline <baseline> --input <검증된-공통입력-폴더>
.\.venv\Scripts\python.exe -B -m extensions.weighted_engine --validate <엔진-출력-폴더>
```

종목 CLI는 지원하는 BE/MSFT/XOM의 최신 저장 입력을 선택한다. 이 엔진 실행 자체는 새 API 수집·외부 모델 호출·훈련·주문을 하지 않는다. 생성한 ENGINE.json, ANALYSIS.json, REPORT.ko.md와 파일 해시는 `reports/private/weighted_engine`의 불변 실행 폴더에 저장한다. 검증은 원래 공통 입력을 재생하고 같은 시각·방법으로 계산·문장·파일을 재생한다. 기존 AI_INPUT/LOCAL_INPUT과 원래 not_run 양식은 수정하지 않는다.

수식·계약·합성 사례의 통과는 수익성 검증이 아니다. 계수의 적절성은 사전 고정한 비용 포함 순차 평가와 보류한 기업·기간의 검증에서 따로 판단해야 한다. 실제 현재 뉴스/재무를 과거 가격 평가에 소급하지 않는다. [SEC의 가상 성과 구분](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-47).
