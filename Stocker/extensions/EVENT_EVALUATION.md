# Priority 3: 사건 이해와 가격 예측을 분리한 평가

`event_evaluation`은 경제 사건의 의미 평가, 시점 적격성, 사건 그룹 및 시간 분리를 담당한다. `event_outcomes`는 별도 로컬 가격·시장·업종·활동량 비교만 담당한다. `event_eval_report`는 승인된 입력과 실제 노출 보고서에서 새 평가 후보를 만들고 원본을 재생한다. 기존 가격 모델·23개 변수·계수·최종 자료·예약은 변경하지 않는다.

사건 발생·최초 공개·원문 발표·수집·최초 이용 가능·분석 기준시각을 구분한다. 없는 시각은 null이다. 회계 결산일·SEC 접수·GDELT 관측을 독립 확인한 최초 공개 시각으로 바꾸지 않는다. 정확한 최초 공개와 원래 사전 예측, 당시 이용 가능한 재무·노출·보관 시각이 확인돼야 가격 평가가 가능하다. 지금 조립한 검토를 과거 발표 당시 예측으로 소급하지 않는다.

미국 XNYS 정규장 달력으로 공개 뒤 시작하는 완전한 5개 세션을 선택한다. 장 마감·단축장·휴일·서머타임을 처리한다. 장중 발표의 다음 세션부터 측정하는 값은 초기 발표 반응 전체가 아니라 후속 정규장 구간이다. 거래대금 근사 분모는 발표 전에 종료한 20개 세션만 쓴다. 동일 사건의 기업별 행과 후속 보도는 그룹으로 묶고, 개발/검증 경계에서 같은 그룹이 양쪽에 걸리거나 관측 구간이 겹치면 보류/제거한다. 묶음 수는 통계적 독립성 인증이 아니다.

가격 데이터 사용권을 확인한 후에만 별도 로컬 reader를 호출한다. 가격·시장·업종의 일치 세션, 기업행동·거래정지·조정 단위를 확인하고 불명확하면 보류한다. 종가×거래량은 실제 체결대금·기관 자금이 아니다. 시장/업종 차감 수익은 단순 관측 비교이며 인과효과·전략 수익이나 기존 예측 대비 개선 인증이 아니다. 이 모듈은 학습하지 않는다.

실제 후보는 SEC 공시 업데이트 3개와 여러 기업이 공유하는 공식 문서 그룹 등으로 구성할 수 있다. 입력·정답·가격은 분리하며 모델 view에는 검증한 SEC 숫자·허용 공식 문단·공시 근거의 노출 상태만 반환한다. 독립 검토 정답은 모델에 주지 않는다. 실제 독립 정답·예측·적격 가격이 없으면 평가 상태는 미실행이다. 자료가 있다는 이유로 평가 통과를 만들지 않는다.

기존 12개 개발 사례나 Priority 1의 모델 눈가림 합성 사례는 실제 사건 성능 표본이 아니다. 최소 30개 사건 그룹이라는 향후 준비 기준도 통계적 검정력 보장이 아니다. 후보 반복 비교·사건 중첩·현재 버전 가격의 한계와 선택 편향을 별도 보고해야 한다. 실제 추가 예측력의 독립 검증 전에는 뉴스 점수·목표가·추천도를 도입하지 않는다.
