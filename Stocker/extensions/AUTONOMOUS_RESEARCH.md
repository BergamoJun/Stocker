# 로컬 원문 판독과 자동 후속 평가

이 확장은 기존 가격 계산과 23변수 가중 엔진을 보존하면서 두 작업을 추가한다. 허용된 공식 원문을 사전학습 언어 모델로 분류하고, 전체 과거 평가가 끝나면 결과 해석과 가격 변수 9개의 계수 관련성을 자동 검사한다. 투자 성능 검증이나 자동 학습을 완료한 단계는 아니다.

## 원문 판독

`local_inference.py`는 프로젝트 내부의 llama.cpp b12110과 공식 Qwen3-4B-GGUF Q4_K_M을 사용한다. 공개 모델 파일의 크기·고정 리비전·SHA-256과 런타임 52개 파일을 확인한다. 모델의 Apache-2.0 허가는 입력 데이터 사용권과 별개다. [공식 모델](https://huggingface.co/Qwen/Qwen3-4B-GGUF), [런타임](https://github.com/ggml-org/llama.cpp/releases/tag/b12110).

추론은 CPU 2개 스레드와 127.0.0.1 인증 연결만 사용한다. 원문은 현재 허용된 연준·EIA 문단으로 제한한다. 가격·가격 파생값·상용 뉴스 메타데이터·API 키는 모델에 전달하지 않는다. 모델 다운로드 이후 판독에는 외부 모델 API나 사용료가 없다. 실행 전 최소 4GB 가용 메모리를 요구하며 자원이 부족하면 다음 실행을 기다린다. 컨텍스트 4,096토큰, 출력 320토큰, 서버 한 번에 최대 24회 요청으로 제한한다.

`semantic_research.py`는 경제 사건 종류·경제 변수 방향·원문에서 직접 고른 인용을 분류한다. 시제와 5거래일 이내 여부는 명시된 원문 표현을 별도 규칙으로 검사한다. 현재 결정이나 과거 관측을 미래 5일 전망으로 바꾸지 않는다. 출처의 지시문은 모델 입력 전에 격리한다. 문단·출처 해시, 최초 실제 판독 시각, 방법과 모델 해시를 저장하며 세 종목이 공유하는 문단은 재사용한다. 거부된 판독도 기록하여 무한 재시도하지 않는다.

보고서는 기존 공통 분석 출력 계약을 검증하며 원문 링크와 조건부 전달 경로·반론을 함께 담는다. 경제 변수 방향이 기업 주가 방향을 증명하지 않으므로 기업 가격 방향은 mixed, 기간은 unknown으로 남긴다. 사람 승인, 전체 세계 뉴스 취재, 가격 인과효과나 최신 사건 40점 축의 충족을 뜻하지 않는다. 정식 추천도·목표가·실현 시기는 계속 보류한다.

## 품질 확인과 기록

1.7B 후보의 첫 검사와 개선 검사는 각각 12건 중 2건, 새 16건 중 12건의 정답으로 기준에 미달했다. 실패한 코드와 결과를 별도 보존했다. 이후 공식 4B 후보를 별도로 등록하여 같은 고정 기준으로 검사했다. 현재 후보의 유효 여부는 `LOCAL_QUALITY.final.json`과 `quality_gate`가 판단한다. 정확도 85%, 계약 수용 90% 이상, 안전 오류 0 등 기존 기준을 낮추지 않는다.

검사는 개발자가 만든 16개 합성 문장에 대한 제한적 준수 시험이다. 문장 분류 성적은 독립적인 실전 뉴스 이해 능력이나 주가 수익률 예측 성능이 아니다. 모델·코드·정책·검사 문장이 달라지면 기존 영수증은 유효하지 않으며 새 후보와 검사가 필요하다.

## 가격 계수 검사

`coefficient_audit.py`는 기존 과거 평가 작업 전체가 완료될 때까지 대기한다. 진행 중인 일부 결과로 계수를 선정하지 않는다. 개발·검증 기업/기간의 기존 결과만 읽고, 잠긴 최종 기업과 마지막 시험 기간은 열지 않는다. 원래 계산 결과를 재생하고 당시 기준일까지의 일봉으로 변수 9개를 복원한다. 현재 뉴스·재무를 과거에 끼워 넣지 않는다.

검사 대상은 수익 기회 25점과 가격 상태 15점에 속한 9개 변수다. 원래 가중 합과 동일 변수의 단순 평균을 같은 완전 관측 사례에서 비교한다. 비교값은 5거래일 보유 후 매수·매도 각각 25bp(각 0.25%) 비용을 반영한 수익률이다. 기준일별 종목 순위와 이후 수익률 순위 사이의 Spearman 상관을 비교하며, 이것은 실제 주문 전략의 수익률 검증이 아니다.

같은 날 종목 간 상관과 5일 구간의 겹침을 고려하여 날짜 묶음 재표집을 사용한다. 기본 묶음 길이 4일, 민감도 2/8일, 반복 2,000회다. 최소 종목 60개와 기준일 16개·명목 묶음 8개 조건을 보며, 누락 날짜나 시간 표본 부족이 있으면 구간 추정을 보류한다. 반복 횟수나 종목×날짜 행 수는 독립 시장 표본 수가 아니다. 어떤 결과도 계수 재학습·정식 점수 승인으로 자동 연결하지 않는다.

## 자동 실행과 중단

`followup_job.py`는 고정된 작업 정의·의존 파일·기존 수집 작업의 무결성을 실행 전후 검사한다. `install_followup_task.ps1 -JobFile <job.json>`은 현재 사용자의 Windows 작업 스케줄러에 창 없는 실행을 등록한다. 5분 간격, 로그인 시와 놓친 예약의 재시도를 사용하며 중복 실행을 막는다. 기존 수집·관찰·SEC 작업을 변경하지 않는다.

컴퓨터가 켜져 있고 현재 사용자가 로그인해야 실행된다. IDE 종료와는 독립적이며 컴퓨터 종료 중에는 실행되지 않는다. 재로그인하면 저장 지점에서 재개한다. 작업은 최대 14일/1,000회이고 한 번에 최대 900초·계수 검사 100기업이다. 자료 API 호출·외부 추론·모델 학습·최종 시험 해제·매매 주문은 수행하지 않는다.

작업 폴더의 `STATUS.ko.md`, `state.json`, 변경 불가 `events/`에서 진행을 확인한다. 무결성·정책·자료 검증 실패는 짧은 중단 사유와 재개 조건을 남긴다. 메모리 부족은 대기하고, 의미 판독 품질 미달은 해당 경로만 보류하여 독립적인 숫자 평가를 계속할 수 있다. 전체 완료나 상한 도달 시 자체 예약을 비활성화한다. `--stop` 또는 작업 폴더의 `STOP` 파일로 중단한다.

현재 개발 기록과 실제 결과는 `reports/private/autonomous_case/20261109/`에 있다. 새 작업은 이 범위의 runtime 기준선을 고정하며, 이후 무관한 확장 추가가 기존 예약을 깨뜨리지 않도록 과거 방법 검증과 현재 확장 목록 검사를 구분한다.
