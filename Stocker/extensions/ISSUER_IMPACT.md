# 기업별 조건부 영향 분석 v1

사용자가 종목을 입력하면 요청형 뉴스 링크와 기존 SEC/공식 원문 근거를 연결하는 별도 실험 CLI다. 기존 가격 예측·계수·다섯 예약 작업은 보존한다. 일반 기업 사건의 자유 해석이나 뉴스에 의한 주가 효과의 추정은 아직 지원하지 않는다.

`issuer_impact`는 공통 계약이 검증한 SEC 수치에서 현금·총부채·설비투자·매출을 기간·단위·귀속·최초 이용 시점으로 선택한다. 기존 로컬 의미 판독을 통과한 연준/EIA 문단 중 요청한 1~30일에 맞고 현재 저장 버전과 일치하는 사건 묶음을 최대 2개 선택한다. 날짜만 있는 발행일이 조회 시작 경계에 걸리면 제외한다. 공식 문서는 일반 회사 기사와 구분한 보완 근거다.

로컬 Qwen3-4B 분석기는 정해진 경제 전달 경로와 정확 인용 중 하나를 선택한다. 이는 제한된 후보 선택이며 범용 기업 분석 완성을 뜻하지 않는다. SEC 숫자는 사업 노출의 증명이 아니다. 총부채를 이자부·변동금리 부채로, 매출을 에너지 판매 노출로 치환하지 않는다. 모든 경로에는 확인되지 않은 가정을 표시하고 단기 효과·점수는 보류한다.

`impact_critic`은 새 문맥에서 같은 모델로 반대 방향·잘못된 사실 ID·확정 노출·5일 주장 등을 검사한다. 별도의 결정 규칙이 모델 승인도 차단할 수 있다. 같은 가중치이므로 통계적으로 독립적인 확인이 아니다. 모델의 원시 검사 성적과 규칙 차단 성적을 구분한다.

`impact_quality_cases.json`은 모델 실행 전에 등록한 자체 작성 12개 이중 프롬프트 사례와 4개 입력 안전 사례다. 정답률 85%, 계약 수용 90%, 잘못된 원시 승인 0건, 안전 오류 0건을 요구한다. 미달이면 실제 AI 분석을 보류하고 실패 기록을 보존한다. 개발 사례 성적을 눈가림 실제 뉴스·주가 성능으로 표현하지 않는다.

메모리·런타임 문제로 검사를 시작하지 못하면 `quality_not_run`으로 기록하고 사례 성적을 생성하지 않는다. 이때 보고서는 규칙으로 구성한 조건부 검토 후보·재무 사실·공식 문단·뉴스 링크까지만 제공하고 AI 채택과 점수는 보류한다. 미실행과 품질 실패는 별도 상태다.

AI 입력은 허용 SEC 사실 숫자·공개 SEC 식별·연준/EIA 문단으로 한정한다. 공급자 가격·파생값·기사 제목·본문·메타데이터는 양쪽 모델 문맥에 넣지 않는다. 뉴스 링크는 로컬 보고서에만 조합하고 저장 시각·주제별 공백·미검색 구간을 표시한다. 외부 AI·학습·새 상시 수집·주문·유료 구독은 없다.

사용 예시(현재 완료 기록의 실제 baseline/quality 경로를 사용):

```powershell
.venv/Scripts/python.exe -B -m extensions.impact_report --ticker BE --days 7 --baseline <runtime.json> --quality <QUALITY.json> --news <기존_요청형_뉴스_폴더>
.venv/Scripts/python.exe -B -m extensions.impact_report --validate <생성된_보고서_폴더>
```

`--news` 생략 시 기존 공유 예산의 요청형 수집을 먼저 실행하며 `--offline-news`로 네트워크 없이 조회할 수 있다. 저장 뉴스 재사용은 현재 조회로 표시하지 않는다. 불변 JSON·한국어 문서·출처/방법/파일 해시를 저장하고 원본 계약·기업·시각·결과를 재생한다. 별도 실제/가상 공간, 보고서 1,000개/128 MiB/개당 1 MiB 한도이며 기존 파일을 삭제하지 않는다.
