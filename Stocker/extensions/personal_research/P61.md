# P6.1 ChatGPT 수동 업로드용 Research Packet

```powershell
.\.venv\Scripts\python.exe -m extensions.personal_research --ticker MU --export-research-packet --offline
.\.venv\Scripts\python.exe -m extensions.personal_research --validate <생성-폴더>
```

생성된 폴더의 RESEARCH_PACKET.md 또는 같은 내용의 RESEARCH_PACKET.json과
ANALYSIS_PROMPT.md를 ChatGPT에 직접 업로드한다. PACKET_MANIFEST.json은 파일 해시와
출처/완결성/제외 정책을 기록한다. 폴더 경로와 UUID는 내보내는 문서에 포함하지 않는다.
자동 업로드·AI·API·모델 호출·새 자료 취득은 없다. API 키와 SDK가 없어도 동작한다.

기존 P6 canonical SEC packet, Typed Evidence, 원문 Resolver 및 금융 계산을 재사용한다.
추가 SEC 재무상태표/재무비교·사업/위험 근거를 기간·단위·귀속과 함께 제공하며 문단은
중복을 제거한다. FY/FQ는 원문 연결이 확립되지 않으면 UNKNOWN, 정확한 기간과 일수는
유지한다. 누락은0이 아니다. 미래 API adapter는 JSON의 canonical_packet을 재사용할 수
있으며 새로운 정량 계산을 수행하지 않는다. 기존 API provider 및 비용·승인 정책은 유지한다.

수동 업로드도 외부 전송이다. 공개 SEC 관측/계산만 기본 허용하며 가격·배수·가격 파생
시나리오·개인 계좌/포지션·비공개 원문/정답·SHADOW 점수와 목표가·인증정보는 제외한다.
밸류에이션 수치가 제한되는 이유를 packet에 표시한다. 내부 결정론적 메모에는 기존 결과가
그대로 남는다. 현재 자료만으로 완전한 산업·경쟁/시장 정보가 확보됐다고 주장하지 않는다.

P6의34개 방법 파일을 v6/에 바이트 그대로 보존하며 이전 계약 보고서는 역사 검증기로
재생한다. 기존 금융·로컬 모델·API 명령의 기능은 보존한다. commit/push는 수행하지 않는다.
