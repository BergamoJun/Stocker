# P5.4 — 실험용 Qwen3.5 연구 기능

실험용 주력 프로필은 **qwen35-4b**다. P5.3의 상대적 비교를 사용한 모델 선택이며,
검증된 금융 추론 능력은 `NOT_ESTABLISHED`, 독립 의미 정확도는 `NOT_MEASURED`다.
P5.3의 실패 관문·원본 응답·판정은 변경하지 않는다.

```powershell
python -m extensions.personal_research --ticker MSFT --memo --ai --ai-model qwen35-4b --ai-mode research
python -m extensions.personal_research --ticker MU --memo --ai --ai-model qwen35-4b --ai-mode research
python -m extensions.personal_research --ticker BE --memo --ai --ai-model qwen35-4b --ai-mode verified
python -m extensions.personal_research --ticker MSFT --memo --ai-model qwen35-4b --ai-dry-run
python -m extensions.personal_research --validate <생성된-private-폴더>
```

개정 계약 `personal-research-v5.4-r2`는 한 번의 CUDA 세션에서 역할별 최대3회 호출한다.
통합 응답의 출력 한도 문제로 변경했으며 최초 P5.4의 응답/실패·27개 소스는 `v54/`로 보존했다.
`v54r1/`에는 중복 본문 제거 전의27개 소스를 보존했다. 동일 본문은 원래 ID·범위·출처를
유지한 채 `text_reference`로 한 번만 제공한다. 다른 문단이나 재무 관측을 임의 합치지 않는다.
저장 응답을 다른 모드에서 새 추론 없이 검증하려면 원래 기준시각을 고정하고 다음처럼 실행한다.

```powershell
python -m extensions.personal_research --ticker MSFT --as-of <원래-분석시각> --ai --ai-model qwen35-4b --ai-mode verified --ai-record <원래-폴더/AI_RECORD.json>
```

이는 저장 모델 실행 증거의 재생이며 새로운 실제 추론으로 집계하지 않는다. 원문·context·프로필·
요청/스키마·원시 응답·CUDA 실행 로그를 다시 확인한다.

기본 실행과 기존 `--ai`는 기존대로 동작한다. 기존 모델의 `roles/integrated/selective`와
새 모델의 `research/verified`는 서로 혼용하지 않는다. 모델 다운로드·외부 AI·CPU fallback은
없다. 기존 CUDA 실행기/공유 lock/물리 RAM·여유 VRAM 관문을 그대로 재사용한다.

Research 모드의 `RESEARCH_MEMO.ko.md`는 Python이 복원한 관측 사실과
`AI_RESEARCH_DRAFT / GROUNDING_CHECKED / SEMANTIC_REVIEW_NEEDED` 가설을 분리한다.
어휘 휴리스틱 실패만으로 초안을 모두 숨기지 않는다. `HARD_REJECT`는 정상 목록에서 빼고
개발 진단 `AI_RECORD.json / AI_VALIDATION.json`에 보존한다. `AI_RESEARCH.json`에는
정상 연구 초안만 포함한다. 금액·백분율·날짜는 모델 문장으로 재생성하지 않고 근거 표에서 제공한다.

Verified 모드는 `MEMO.ko.md`에 검증되지 않은 AI 해석을 넣지 않는다. 현재 계약은 자유 형식
경제 해석을 독립 의미 검증 없이 자동 `SEMANTIC_PASS/VERIFIED`로 승격하지 않는다.
따라서 실제 의미 검토가 확보되지 않은 응답은 `SEMANTIC_REVIEW_NEEDED`이고 정식 메모는
`DETERMINISTIC_FALLBACK`이다. 이 상태가 모델 등록이나 Research 모드 실행을 막지는 않는다.
독립 의미 검토 영수증의 수입/승인 워크플로는 이번 계약에 포함하지 않았다.

Typed Evidence는 제품·고객·사업부·연결회사 범위, 대상, 측정 종류, 단위·기간·관측 종류를
표시한다. 공시 문단에 비교기간이 명시되지 않으면 `UNKNOWN`이며, filing 날짜로 YoY를
만들지 않는다. 제품 매출 성장과 출하량, 고객 보상과 회사 매출, 현금 CAPEX와 OCF를 구분한다.
재무 비교값은 현재 확보한 공시의 비교열이며 원래 시점 PIT나 장기 평균으로 표시하지 않는다.

기존 P5.1-r1의20개 방법 파일은 `v51r1/`에 원래 바이트 그대로 보관하고 이전 계약의
보고서만 그 검증기로 dispatch한다. 과거 validator를 완화하지 않는다. 기본 금융·시장 계산,
23요인·SHADOW·P4·예약 작업은 그대로다. 모든 실제 출력은 ignored private 폴더에 저장한다.
