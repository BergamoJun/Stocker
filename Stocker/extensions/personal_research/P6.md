# P6 — GPT-6.1 Sol 전문 리서치

Python 재무·P4 계산과 기존 로컬 Qwen을 보존하고, 명시적으로 선택하는 OpenAI
Responses API 경로를 추가했다. `gpt-6.1-sol`, 기본 `high`, 선택 `xhigh`, 기업당
통합 요청 한 회다. Structured Outputs와 출처 검사는 경제적 의미 정확도의 인증이 아니다.

Stocker Python 프로젝트 폴더에서 실행한다.

```powershell
# 선택 기능의 SDK 설치. 기존 금융/로컬 모델 기본 실행에는 필요하지 않다.
.\.venv\Scripts\python.exe -m pip install -r extensions/personal_research/requirements-openai.txt

# 기본 결정론적 보고서, 기존 --ai 및 qwen35-4b 동작은 유지한다.
.\.venv\Scripts\python.exe -m extensions.personal_research --ticker MSFT --memo --offline

# 키와 전송 승인 없이 전송 검사·비용 추정·보고서 경로를 확인한다. API 요청 0회.
.\.venv\Scripts\python.exe -m extensions.personal_research --ticker MSFT --memo --ai --ai-provider openai --ai-model gpt-6.1-sol --ai-mode research --dry-run

# OPENAI_API_KEY는 실행 프로세스 환경변수로만 설정한다. 키를 채팅/문서/명령 인수에 넣지 않는다.
# 사용자가 전송과 비용을 명시적으로 승인한 뒤에만 아래 라이브 명령을 실행한다.
.\.venv\Scripts\python.exe -m extensions.personal_research --ticker MSFT --memo --ai --ai-provider openai --ai-model gpt-6.1-sol --ai-mode research --reasoning high --allow-cloud --allow-paid --max-api-usd 2

# 원래 기준시각으로 저장 응답을 검증 재사용한다. 새로운 유료 요청이 아니다.
.\.venv\Scripts\python.exe -m extensions.personal_research --ticker MSFT --as-of <원래-기준시각> --ai --ai-provider openai --ai-model gpt-6.1-sol --ai-mode verified --ai-record <원래-private-폴더/API_RECORD.json> --offline
.\.venv\Scripts\python.exe -m extensions.personal_research --validate <생성된-private-폴더>
```

`STOCKER_AI_PROVIDER=openai`는 명시적 환경 선택이다. 미설정 기본값은 `local`이다.
`STOCKER_OPENAI_MODEL=gpt-6.1-sol`, `STOCKER_OPENAI_REASONING=high`,
`STOCKER_OPENAI_STORE=false`를 지원하며 다른 상용 모델/저장은 거절한다.
`OPENAI_BASE_URL`·proxy 환경으로 목적지를 바꾸지 않는다. 기본 pytest는 라이브 API를
호출하지 않는다. 키가 없으면 `NOT_RUN_NO_API_CREDENTIALS`, 전송/유료 승인이 없으면
`NOT_RUN_CLOUD_OR_PAID_PERMISSION_REQUIRED`로 기록하며 결정론적 메모를 유지한다.
실제 호출과 `--offline`을 함께 지정하면 오류다. dry-run/저장 재생은 offline에서 가능하다.

## 전송 범위와 보고서

공개 SEC 원문의 선택 근거와 해시·locator·제출일·최초 이용 시각·기간·통화·단위·범위를
보존한다. 내부 원문 경로·사용자명·계좌·포지션·비공개 평가 정답·공급자 가격·가격 파생
배수/시나리오·뉴스는 전송하지 않는다. Typed Evidence/기존 Resolver를 재사용하며 동일
문단은 한 번만 보낸다. SEC에서 확인되지 않는 분류·정보는 UNKNOWN이다.

P4 수치 자체는 private 결정론적 메모에 남는다. 외부 제공 권리가 확인되지 않는 시세·배수와
파생 가치는 모델 입력에서 `WITHHELD_EXTERNAL_MARKET_DATA_RIGHTS`로 제한한다.
독립적인 SEC 입력에 연결되거나 사용자가 명시한 비가격 경제 시나리오 가정만 전송한다.
모델이 보지 못한 밸류에이션의 적정성까지 분석했다고 주장하지 않는다.

출력은 `RESEARCH_REPORT.ko.md`, `OPENAI_MODEL_PROFILE.json`, `RESEARCH_PACKET.json`,
`API_RECORD.json`, `AI_RESEARCH_RESULT.json`, `API_USAGE.json`, `API_COST_REPORT.json`,
`VALIDATION_RESULTS.json`이다. 모두 ignored private UUID 폴더에 저장한다.
Research에는 hard 검사를 통과한 AI 해석을 `AI_ANALYST_INTERPRETATION /
SEMANTIC_REVIEW_NEEDED`로 표시한다. hard 기각은 진단에 보존한다. 숫자/기간은 원본
Evidence placeholder와 Python 표로 표시하고 모델이 새 수치를 계산하지 않는다.
Verified에는 의미 검토 없이 AI를 승격하지 않으며 결정론적 fallback을 유지한다.
독립 의미 검토 영수증 수입·양성 승인 경로는 아직 없다. 모델 응답은 출처나 검토자가 아니다.

## 비용과 실패

공유 기본 ledger는 `local_data/p6_openai_budget/initial-v1.json`이다. MSFT/MU/BE가
총 USD 2.00, 최대 HTTP 시도 3회를 공유한다. 매 CLI 실행마다 예산을 초기화하지 않는다.
`--api-budget-ledger`는 해당 private 디렉터리 내부의 명시적 새 실험 ledger를 선택한다.
기존 ledger 한도 변경은 거절하며, 새 실험은 사용자가 별도로 승인해야 한다.

SDK 자동 retry=0. 기본 시도=1, `--api-max-attempts 2`에서만 429/5xx를 잔여 예산 내
최대 한 번 재시도한다. Retry-After를 지키며 60초를 넘으면 재시도를 보류한다.
인증/권한/과금/모델 접근 오류와 불확실한 timeout은 자동 재시도하지 않는다.
요청 전 USD 예약을 process lock 아래 기록하며, crash/불확실한 결과는 예약을 유지한다.
실제 usage가 있으면 사용량 기반 추정액으로 정산한다. 다른 모델 fallback은 없다.

오프라인 입력 추정은 UTF-8 byte 수+1024이며 실제 토크나이저 측정이나 청구액 보증이 아니다.
출력은 추론 포함 기본8192(명시 범위1024~16384) 토큰이다. 입력 추정 최대100000으로
장문 할증 구간을 사용하지 않는다. 입력/캐시 읽기/캐시 쓰기/출력 사용량을 분리한다.
reasoning token은 output에 포함하므로 다시 더하지 않는다. 가격 기준일2026-11-18,
Standard 1M token당 input $2 / cached $0.10 / cache write $2.50 / output $10이다.
`actual_invoice_usd`는 별도 청구 검증 없이 null이다. 실패 응답도 유료일 수 있다.

`store=false`는 응답의 기본 저장을 제한하며 모든 서비스 로그·캐시를 없애는 설정이 아니다.
기본 abuse monitoring 보존(통상 최대30일), 별도 캐시 보존 및 계정 데이터 제어를 고려한다.
Zero Data Retention 계정이라고 가정하지 않는다.
